Animacoes com @keyframes

Enquanto transicoes interpolam entre dois estados, animacoes CSS permitem criar sequencias complexas com multiplos passos. Voce define os keyframes (quadros-chave) e o navegador preenche o movimento entre eles. Animacoes podem rodar sozinhas, repetir infinitamente e reverter direcao — tudo sem JavaScript.

O que sao @keyframes

A regra @keyframes define uma sequencia de estilos que o elemento vai assumir ao longo do tempo. Voce escolhe um nome para a animacao e descreve os estados com from / to ou com porcentagens. 

/* Sintaxe com from/to */
@keyframes aparecer {
  from {
    opacity: 0;
    transform: translateY(20px);
  }
  to {
    opacity: 1;
    transform: translateY(0);
  }
}

/* Sintaxe com porcentagens */
@keyframes pulsar {
  0%   { transform: scale(1); }
  50%  { transform: scale(1.15); }
  100% { transform: scale(1); }
}

from e o mesmo que 0%, e to e o mesmo que 100%. Porcentagens permitem criar quantos passos intermediarios voce precisar.

Aplicando a animacao

Depois de definir os keyframes, use a propriedade animation para aplicar no elemento: 

/* Passo 1: definir os keyframes */
@keyframes aparecer {
  from { opacity: 0; transform: translateY(20px); }
  to   { opacity: 1; transform: translateY(0); }
}

/* Passo 2: aplicar no elemento */
.titulo {
  animation: aparecer 0.6s ease-out forwards;
}

Diferente de transition, voce nao precisa de :hover para disparar. A animacao roda assim que o CSS e aplicado ao elemento.

Codigo das demos

/* Pulse — escala sobe e desce */
@keyframes pulse {
  0%, 100% { transform: scale(1); opacity: 1; }
  50% { transform: scale(1.15); opacity: 0.8; }
}
.pulse { animation: pulse 2s ease-in-out infinite; }

/* Spin — rotacao continua */
@keyframes spin {
  from { transform: rotate(0deg); }
  to   { transform: rotate(360deg); }
}
.spin { animation: spin 2s linear infinite; }

/* Bounce — pulo com quiques */
@keyframes bounce {
  0%, 100% { transform: translateY(0); }
  25% { transform: translateY(-20px); }
  50% { transform: translateY(0); }
  75% { transform: translateY(-10px); }
}
.bounce { animation: bounce 1.5s ease infinite; }

/* Color shift — troca de cor gradual */
@keyframes color-shift {
  0%   { background: #e11d48; }
  33%  { background: #7c3aed; }
  66%  { background: #0891b2; }
  100% { background: #e11d48; }
}
.color { animation: color-shift 4s ease infinite; }

As 8 sub-propriedades de animation

Propriedade O que faz Valores comuns
animation-name Nome do @keyframes a usar aparecer, pulse, spin
animation-duration Quanto tempo dura um ciclo 0.5s, 1s, 2s, 300ms
animation-timing-function Ritmo / curva de velocidade ease, linear, cubic-bezier()
animation-delay Espera antes de comecar 0s, 0.3s, -0.5s
animation-iteration-count Quantas vezes repete 1, 3, infinite
animation-direction Direcao de reproducao normal, reverse, alternate
animation-fill-mode Estilos antes/depois da animacao none, forwards, backwards, both
animation-play-state Pausar ou rodar running, paused

Shorthand animation

O shorthand junta tudo em uma linha. A ordem recomendada pela MDN: 

/* Ordem recomendada */
animation: name duration timing-function delay
           iteration-count direction fill-mode play-state;

/* Exemplo completo */
animation: aparecer 0.6s ease-out 0.2s 1 normal forwards running;

/* Exemplo minimo (name + duration) */
animation: aparecer 0.6s;

/* Com infinite e alternate */
animation: pulse 2s ease-in-out infinite alternate;

Assim como em transition, se voce escrever dois valores de tempo, o primeiro e a duration e o segundo e o delay. Nao inverta!

animation-direction

Controla em qual sentido a animacao roda:

Valor Comportamento
normal Roda do from ao to (padrao)
reverse Roda do to ao from
alternate Alterna: ida normal, volta reverse
alternate-reverse Alterna: ida reverse, volta normal

alternate e otimo para animacoes de "vai e volta" como pulse e bounce. Evita o pulo de volta ao estado inicial.

animation-fill-mode

Define qual estilo o elemento mantem antes e depois da animacao:

Valor Comportamento
none Volta ao estilo original quando termina (padrao)
forwards Mantem o estilo do ultimo keyframe (to / 100%)
backwards Aplica o estilo do primeiro keyframe durante o delay
both Combina forwards e backwards 
/* Sem forwards: o elemento volta ao estado original */
animation: aparecer 0.6s ease-out;

/* Com forwards: o elemento fica no estado final */
animation: aparecer 0.6s ease-out forwards;

/* Com both: aplica from durante delay, mantem to no final */
animation: aparecer 0.6s ease-out 0.3s both;

forwards e o mais usado. Sem ele, um elemento que entra com fade-in vai sumir quando a animacao terminar.

animation-play-state

Permite pausar e retomar a animacao. Muito util com :hover para criar animacoes que so rodam quando o usuario interage: 

/* Animacao pausada por padrao */
.elemento {
  animation: spin 2s linear infinite;
  animation-play-state: paused;
}

/* Roda quando passa o mouse */
.elemento:hover {
  animation-play-state: running;
}

Delay negativo

Um delay negativo nao espera — ele pula para um ponto ja avancado da animacao. Util para escalonar elementos que aparecem juntos: 

.item:nth-child(1) { animation-delay: 0s; }
.item:nth-child(2) { animation-delay: -0.2s; }
.item:nth-child(3) { animation-delay: -0.4s; }
.item:nth-child(4) { animation-delay: -0.6s; }

/* Cada item comeca num ponto diferente da animacao,
   criando um efeito de onda */

Com delay negativo em infinite, todos os elementos ja comecam rodando — cada um em um ponto diferente do ciclo.

Diferenca entre transition e animation

Transition
  • precisa de gatilho (:hover, :focus, classe)
  • 2 estados: A → B
  • nao repete sozinha
  • mais simples de escrever
  • ideal para interacoes do usuario
Animation
  • roda sozinha ao carregar
  • multiplos estados via keyframes
  • pode repetir infinitamente
  • mais controle (direction, fill-mode)
  • ideal para efeitos visuais autonomos

Multiplas animacoes no mesmo elemento

Voce pode aplicar varias animacoes separando com virgula, assim como nas transitions: 

.elemento {
  animation:
    aparecer 0.6s ease-out forwards,
    pulse 2s ease-in-out 0.6s infinite;
}

/* Primeiro aparece (0.6s), depois fica pulsando */

Use animation-delay na segunda animacao para que ela comece somente quando a primeira terminar.

Resumo rapido

  1. @keyframes define a sequencia de estados da animacao
  2. use from/to para 2 estados ou % para multiplos
  3. o shorthand animation junta name, duration, timing, delay, iteration, direction, fill e play-state
  4. forwards mantem o estilo final — quase sempre o que voce quer
  5. alternate cria efeitos de vai-e-volta suaves
  6. infinite repete sem parar — otimo para loaders e indicadores
  7. delay negativo pula para um ponto avancado da animacao
