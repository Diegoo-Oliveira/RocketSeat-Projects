Sequencia sugerida

  1. comece pelas transicoes — sao a forma mais simples de movimento
  2. depois estude @keyframes para animacoes continuas e complexas
  3. explore animation-timeline, steps(), cubic-bezier() e linear() para timing avancado
  4. aprenda as transformacoes 2D que sao a base do movimento visual
  5. por fim, explore as transformacoes 3D e efeitos como card-flip

Transicoes e animacoes usam as mesmas timing-functions (ease, linear, cubic-bezier). Dominar uma facilita a outra.

Transicao vs Animacao — quando usar cada uma

Transition
  • precisa de um gatilho (:hover, :focus, classe JS)
  • vai do estado A ao estado B
  • ideal para interacoes do usuario
  • mais simples de escrever
Animation
  • pode rodar sozinha ao carregar a pagina
  • aceita multiplos estados (keyframes)
  • pode repetir infinitamente
  • mais controle: direction, fill-mode, play-state
