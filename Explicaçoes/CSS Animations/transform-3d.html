Transformacoes 3D

Transformacoes 3D adicionam profundidade ao CSS, permitindo girar, mover e posicionar elementos nos eixos X, Y e Z (para dentro e fora da tela). Para que o efeito 3D funcione, voce precisa entender perspective, preserve-3d e backface-visibility.

perspective — a base do 3D

Sem perspective, transformacoes 3D parecem planas. O perspective define a distancia do "olho" do observador ate o elemento. Quanto menor o valor, mais dramatico e o efeito; quanto maior, mais sutil. 

/* Como propriedade no pai (afeta todos os filhos) */
.container {
  perspective: 600px;
}

/* Como funcao no proprio elemento */
.elemento {
  transform: perspective(600px) rotateY(30deg);
}

/* Valores tipicos */
perspective: 200px;  /* muito dramatico */
perspective: 500px;  /* equilibrado */
perspective: 1000px; /* sutil */

Prefira usar perspective como propriedade no pai para que todos os filhos compartilhem o mesmo ponto de fuga. Use como funcao apenas quando quiser efeito isolado.

rotateX, rotateY e rotateZ

Cada funcao gira o elemento em torno de um eixo especifico. Imagine o elemento como um cartao em pe:

Funcao Eixo Efeito visual
rotateX(angle) Eixo horizontal (—) Topo move para frente/tras (como abrir uma tampa)
rotateY(angle) Eixo vertical (|) Lados movem para frente/tras (como abrir uma porta)
rotateZ(angle) Eixo de profundidade (·) Gira no plano da tela (igual rotate() 2D) 
transform: rotateX(45deg);   /* tampa abrindo */
transform: rotateY(45deg);   /* porta abrindo */
transform: rotateZ(45deg);   /* giro no plano */

/* Funcao unificada com vetor */
transform: rotate3d(1, 1, 0, 45deg);
/* Gira 45deg ao redor do eixo definido pelo vetor (1,1,0) */

translate3d e translateZ

Movem o elemento no espaco 3D. O eixo Z e o que vai "para dentro" e "para fora" da tela: 

/* Move em todos os 3 eixos */
transform: translate3d(20px, 10px, 50px);

/* So no eixo Z (profundidade) */
transform: translateZ(50px);   /* vem na direcao do usuario */
transform: translateZ(-50px);  /* afasta do usuario */

/* Precisa de perspective no pai para funcionar */
.container { perspective: 600px; }
.filho     { transform: translateZ(80px); }

translateZ positivo faz o elemento parecer maior (mais perto), negativo faz parecer menor (mais longe). Sem perspective o efeito nao aparece.

scale3d e outras funcoes 3D

/* Escala em 3 dimensoes */
transform: scale3d(1.5, 1.5, 1);
/* scaleZ raramente tem efeito visivel sozinho */

/* Combinando funcoes 3D */
transform: perspective(600px)
           rotateY(30deg)
           translateZ(40px)
           scale(1.1);

/* Ordem: perspective sempre primeiro */

Quando perspective e usada como funcao dentro de transform, ela deve ser a primeira funcao da lista.

transform-style: preserve-3d

Por padrao, filhos de um elemento transformado sao achatados no plano 2D do pai. Para que os filhos mantenham suas posicoes 3D, voce precisa de preserve-3d. 

/* Sem preserve-3d: filhos ficam planos */
.pai {
  transform: rotateY(30deg);
}

/* Com preserve-3d: filhos existem em 3D */
.pai {
  transform: rotateY(30deg);
  transform-style: preserve-3d;
}
.filho {
  transform: rotateX(20deg) translateZ(40px);
  /* Agora esse translate funciona em 3D real */
}
Valor Comportamento
flat Filhos sao achatados no plano do pai (padrao)
preserve-3d Filhos mantem posicao no espaco 3D

backface-visibility

Quando voce gira um elemento mais de 90 graus, o "verso" dele fica virado para o usuario. Por padrao esse verso e visivel (mostra o conteudo espelhado). Com backface-visibility: hidden, o elemento desaparece quando mostra as costas. 

/* Verso visivel (padrao) */
backface-visibility: visible;

/* Verso escondido */
backface-visibility: hidden;

/* Essencial para efeito card-flip:
   a face de tras so aparece quando o cartao vira */
Valor Comportamento
visible Verso aparece espelhado (padrao)
hidden Elemento some quando mostra as costas

Exemplo pratico: Card Flip

O efeito de virar um cartao e o exemplo classico de 3D no CSS. Ele usa perspective, preserve-3d, backface-visibility e rotateY juntos.

Verso

Codigo do Card Flip

/* 1. Container com perspective */
.flip-scene {
  perspective: 800px;
  width: 220px;
  height: 140px;
}

/* 2. Cartao que gira */
.flip-card {
  position: relative;
  width: 100%;
  height: 100%;
  transition: transform 0.7s ease;
  transform-style: preserve-3d;
}

/* 3. Hover gira 180 graus */
.flip-scene:hover .flip-card {
  transform: rotateY(180deg);
}

/* 4. Faces do cartao */
.flip-face {
  position: absolute;
  inset: 0;
  display: grid;
  place-items: center;
  border-radius: 16px;
  backface-visibility: hidden;
}

/* 5. Frente: estilo normal */
.flip-front {
  background: #e11d48;
  color: #ffffff;
}

/* 6. Verso: ja comeca virado */
.flip-back {
  background: #7c3aed;
  color: #ffffff;
  transform: rotateY(180deg);
}

O truque e: a face de tras ja comeca com rotateY(180deg). Quando o cartao inteiro gira 180 graus, a frente fica escondida (backface hidden) e o verso aparece de frente.

Tabela resumo — propriedades 3D

Propriedade / Funcao O que faz
perspective Define a distancia do observador (ponto de fuga)
perspective-origin Muda a posicao do ponto de fuga (padrao: center)
transform-style flat ou preserve-3d — filhos em 2D ou 3D
backface-visibility visible ou hidden — mostra ou esconde o verso
rotateX(angle) Gira no eixo horizontal
rotateY(angle) Gira no eixo vertical
rotateZ(angle) Gira no plano da tela
rotate3d(x, y, z, angle) Gira em eixo customizado
translate3d(x, y, z) Move em todos os 3 eixos
translateZ(z) Move na profundidade (perto/longe)
scale3d(x, y, z) Escala em 3 dimensoes

Dicas de performance 3D

  1. GPU acceleration: translate3d(0, 0, 0) e um truque classico para forcar o navegador a usar a GPU, mesmo sem movimento real.
  2. will-change: use will-change: transform para avisar o navegador que o elemento vai ser transformado em breve.
  3. Evite overflow: hidden no pai: pode cortar elementos que se movem no eixo Z.
  4. Cuidado com preserve-3d em cascata: alguns navegadores nao propagam preserve-3d por mais de um nivel. 
/* Truque de GPU acceleration */
.elemento-que-vai-animar {
  will-change: transform;
  transform: translate3d(0, 0, 0);
}

/* Remova will-change depois que nao precisar mais,
   pois consome memoria da GPU */

will-change nao e magica — use com moderacao. Aplicar em muitos elementos ao mesmo tempo pode piorar a performance em vez de melhorar.

Resumo rapido

  1. perspective e obrigatorio para efeitos 3D — define a distancia do olho
  2. valores menores de perspective = efeito mais dramatico
  3. rotateX = tampa, rotateY = porta, rotateZ = plano
  4. translateZ move na profundidade (precisa de perspective)
  5. preserve-3d faz os filhos existirem em 3D real
  6. backface-visibility: hidden esconde o verso — essencial para card-flip
  7. translate3d(0,0,0) forca GPU acceleration
