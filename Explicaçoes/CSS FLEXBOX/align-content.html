align-content

align-content distribui as linhas de itens no eixo cruzado. Ele so faz efeito quando existem varias linhas, entao o container precisa usar flex-wrap: wrap. 

.container {
  display: flex;
  flex-wrap: wrap;
  align-content: center;
}

flex-start

As linhas sobem e ficam agrupadas no inicio do container.

align-content: flex-start;

center

O bloco de linhas vai para o centro do eixo cruzado.

space-between

A primeira linha vai para cima, a ultima desce e o espaco do meio e distribuido entre as linhas. 

align-content: space-between;
1
2

Diferenca importante: align-items mexe em cada item dentro da linha. align-content mexe no conjunto das linhas.
