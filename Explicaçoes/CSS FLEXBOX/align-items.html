Voltar para o indice align-items

align-items

align-items alinha os itens no eixo cruzado. Em um layout com flex-direction: row, isso normalmente parece um alinhamento vertical. 

.container {
  display: flex;
  align-items: center;
}

flex-start

Todos os itens sobem para o inicio do eixo cruzado.

align-items: flex-start;
A
B
C

center

Os itens ficam centralizados no eixo cruzado.

align-items: center;
A
B
C

flex-end

Os itens descem para o fim do eixo cruzado.

align-items: flex-end;
A
B
C

stretch

Se os itens nao tiverem altura fixa, eles podem se esticar para ocupar o espaco do eixo cruzado. 

align-items: stretch;
A
B
C

Regra mental: align-items age em todos os filhos de uma vez so. Se voce quiser alterar apenas um item, use align-self no proprio filho.
