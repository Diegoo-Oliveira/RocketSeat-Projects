Children no Flexbox

Children nao e uma propriedade do CSS. Esse termo representa os filhos diretos do container flex. Sao eles que respondem a propriedades como flex-grow, order e align-self. 

<div class="container">
  <div class="item">A</div>
  <div class="item">B</div>
  <div class="item">C</div>
</div>

flex-grow

Faz o filho crescer para ocupar o espaco livre. Quanto maior o numero, maior a fatia que ele recebe. 

.item-1 { flex-grow: 1; }
.item-2 { flex-grow: 2; }
1
2
3

order

Muda a ordem visual dos itens sem alterar a ordem do HTML. 

.primeiro { order: -1; }
.ultimo { order: 3; }
A
B
C

align-self

Permite alinhar um unico filho de forma diferente dos demais. 

.destaque { align-self: flex-end; }
A
B
C

Resumo: o pai controla a distribuicao geral com propriedades de container. Os children podem receber ajustes individuais com propriedades aplicadas diretamente neles.
