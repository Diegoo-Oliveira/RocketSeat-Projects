Voltar para o indice Figma + Flexbox

Como recriar a pagina do node 3:376

Agora sim estamos olhando para a tela certa: a pagina interna do perfil no Travelgram, com cabecalho, bloco do usuario, grade de imagens e rodape. Esta explicacao foi montada com base na captura que voce enviou do node 3:376.

O ponto principal aqui e este: quase toda a pagina pode ser pensada com Flexbox, mas a grade de fotos fica bem melhor com Grid. Entender essa divisao faz a recriacao ficar muito mais proxima do Figma.

As linhas azuis vistas no print sao marcacoes do editor do Figma sobre o bloco de nome e descricao. Elas nao fazem parte da interface final, entao a recriacao abaixo considera a tela pronta.

Leitura correta do print

  1. header branco com logo a esquerda e menu discreto a direita
  2. faixa de perfil em cinza claro com avatar, nome, bio e dados
  3. galeria com 12 fotos em 4 colunas
  4. rodape simples com copyright e links

Essa e a pagina interna do perfil. Nao e a capa do projeto, nem uma secao isolada.

1. Estrutura geral da pagina

Essa tela e uma pagina interna de perfil. Se voce quebrar o layout em blocos, ela fica assim:

  1. header superior com marca e menu
  2. secao do perfil com avatar, bio e estatisticas
  3. grade de 12 imagens
  4. rodape simples com links
<main class="app">
  <header>...</header>
  <section class="profile">...</section>
  <section class="gallery">...</section>
  <footer>...</footer>
</main>

Quando voce enxerga a hierarquia certa, o CSS fica muito mais simples.

2. O app inteiro e uma coluna

O container principal pode ser tratado como uma pilha vertical de grandes secoes. 

.app {
  display: flex;
  flex-direction: column;
}

O header vem primeiro, depois o perfil, depois a galeria e por fim o rodape.

3. O header usa Flexbox horizontal

A barra superior tem dois grupos: marca na esquerda e navegacao na direita. 

.header {
  display: flex;
  justify-content: space-between;
  align-items: center;
}

Esse e um caso classico de justify-content: space-between.

4. O bloco do perfil tambem e Flexbox

A secao central e formada por tres children principais no mesmo eixo:

  1. avatar
  2. texto do perfil
  3. lista de estatisticas
.profile {
  display: flex;
  justify-content: space-between;
  align-items: flex-start;
  gap: 32px;
}

Aqui o Flexbox organiza tudo em linha e o gap cria respiracao entre os blocos.

O fundo mais claro dessa faixa e apenas aparencia. A organizacao do avatar, texto e dados continua sendo trabalho do Flexbox.

5. A bio do usuario e outra coluna

Dentro da parte central, nome e descricao ficam empilhados. 

.profile-copy {
  display: flex;
  flex-direction: column;
  gap: 8px;
}

Esse e o tipo de detalhe que costuma passar despercebido no Figma, mas faz muita diferenca na hora de montar.

6. As estatisticas ficam em coluna

A lista da direita pode ser pensada como um pequeno menu vertical. 

.profile-stats {
  display: flex;
  flex-direction: column;
  gap: 12px;
}

Ou seja: ate dentro de um layout grande, voce vai usando Flexbox em blocos menores.

7. A galeria e melhor com Grid

Aqui esta a parte mais importante da fidelidade visual. A grade de fotos do Figma tem 4 colunas fixas e 3 linhas. 

.gallery {
  display: grid;
  grid-template-columns: repeat(4, 1fr);
  gap: 16px;
}

Da para fazer com flex-wrap? Da. Mas para ficar realmente igual ao Figma, Grid e a escolha mais limpa.

Para estudar Flexbox, vale testar uma versao com flex-flow: row wrap. Para copiar esta tela com fidelidade, Grid resolve melhor.

8. O rodape volta para Flexbox

O rodape tem texto pequeno na esquerda e links na direita. 

.footer {
  display: flex;
  justify-content: space-between;
  align-items: center;
}

Esse e outro padrao muito comum em interfaces reais.

Mapa mental desta tela

  1. estrutura principal: coluna vertical
  2. header: Flexbox horizontal
  3. perfil: Flexbox horizontal
  4. bio e estatisticas: pequenas colunas com Flexbox
  5. galeria: Grid
  6. rodape: Flexbox horizontal
