Alinhamentos items

align-items e justify-items alinham todos os itens dentro de suas celulas. A grade nao muda de lugar; quem se move sao os elementos dentro dos espacos.

Exemplo visual

As celulas continuam grandes, mas os itens dentro delas ficaram centralizados.

Codigo

.container {
  display: grid;
  grid-template-columns: repeat(3, 72px);
  grid-template-rows: repeat(2, 58px);
  align-items: center;
  justify-items: center;
}

items afeta todos os itens. Para afetar so um, use self.
