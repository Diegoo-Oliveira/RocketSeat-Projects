Alinhamentos self

align-self e justify-self alinham apenas um item dentro da propria celula. Eles vencem o alinhamento geral daquele item especifico.

Exemplo visual

Apenas o item laranja foi levado para o canto inferior direito da celula.

self
3

Codigo

.item-especial {
  align-self: end;
  justify-self: end;
}

Use self para excecoes. Use items para alinhar todos os filhos de uma vez.
