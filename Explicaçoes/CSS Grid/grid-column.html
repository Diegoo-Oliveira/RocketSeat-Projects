Grid Column

grid-column controla onde um item comeca e termina no eixo das colunas. Ele usa as linhas invisiveis da grade, nao apenas o numero das colunas.

Exemplo visual

O item laranja comeca na linha 2 e termina na linha 5. Por isso ele ocupa tres colunas.

1
2
3
4
grid-column: 2 / 5

Codigo

.container {
  display: grid;
  grid-template-columns: repeat(4, 1fr);
}

.item-destaque {
  grid-column: 2 / 5;
}

Em uma grade com 4 colunas existem 5 linhas verticais: antes da primeira coluna, entre as colunas e depois da ultima.
