Grid Template Areas

grid-template-areas permite nomear regioes da grade. Isso deixa layouts grandes mais legiveis, quase como desenhar um mapa da pagina dentro do CSS.

Exemplo visual

top
side
content
foot

Codigo

.container {
  display: grid;
  grid-template-columns: 1fr 2fr;
  grid-template-areas:
    "top top"
    "side content"
    "foot foot";
}

.top { grid-area: top; }
.side { grid-area: side; }
.content { grid-area: content; }
.foot { grid-area: foot; }

O mesmo nome repetido faz a area ocupar mais espaco. No exemplo, top atravessa as duas colunas.
