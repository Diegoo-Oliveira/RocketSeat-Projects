Guia visual para estudar CSS Grid

CSS Grid organiza layouts em linhas e colunas. Ele e excelente para montar galerias, dashboards, areas nomeadas e paginas com blocos bem definidos. Cada pagina abaixo mostra um conceito com exemplos visuais.

Grid Template Rows

Controle a altura das linhas explicitas da grade.

Grid Column

Faca um item ocupar colunas especificas usando linhas da grade.

Grid Row

Faca um item ocupar linhas especificas, criando cards altos.

Grid Template Areas

Nomeie partes do layout como topo, menu, conteudo e rodape.

Gap

Controle o espaco entre linhas e colunas sem margens manuais.

Shorthand grid-template

Junte areas, linhas e colunas em uma declaracao compacta.

Introducao aos alinhamentos

Entenda a diferenca entre content, items e self no Grid.

Alinhamentos content

Distribua a grade inteira dentro do container.

Alinhamentos items

Alinhe todos os itens dentro das celulas.

Alinhamentos self

Alinhe apenas um item diferente dos outros.

Propriedades grid auto

Controle linhas e colunas criadas automaticamente pelo navegador.

Grid ou Flex

Escolha a ferramenta certa para cada tipo de layout.

Sequencia sugerida

  1. comece por linhas, colunas e gap
  2. depois avance para areas e shorthand
  3. estude alinhamentos na ordem: content, items e self
  4. termine comparando Grid ou Flexbox
