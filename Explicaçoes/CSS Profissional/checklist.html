Voltar para CSS Profissional Checklist

Checklist para revisar seus layouts

Use esta lista quando terminar um projeto. Ela ajuda a enxergar se o CSS esta apenas funcionando ou se tambem esta organizado para crescer.

1. Repeticao

  • Tenho varias classes com as mesmas propriedades?
  • Consigo transformar isso em uma classe unica?
  • A largura fixa e realmente necessaria?

2. Nomes de classe

  • O nome descreve um padrao ou apenas um item especifico?
  • .content-tag e mais reutilizavel que .content-tag-robotica.
  • .section-header e mais reutilizavel que #aside-head.

3. Layout

  • A pagina grande esta organizada com Grid?
  • Componentes internos usam Flexbox ou Grid de forma simples?
  • O espaçamento esta vindo de gap quando possivel?

4. Organizacao

  • Tokens globais ficam no arquivo global?
  • Header, secoes e utilitarios estao separados?
  • As regras de uma secao estao agrupadas no mesmo lugar?

Regra mental simples

Quando voce for criar uma classe, pergunte: "isso e uma coisa unica da tela ou e um padrao que pode aparecer de novo?".

Quando ser especifico?

Ser especifico nao e errado. Use uma classe ou ID especifico quando a parte da tela realmente tem comportamento unico. O problema aparece quando voce usa especificidade para elementos que compartilham o mesmo visual.

Profissional nao significa complexo. Profissional significa facil de entender, facil de mudar e dificil de quebrar sem perceber.
