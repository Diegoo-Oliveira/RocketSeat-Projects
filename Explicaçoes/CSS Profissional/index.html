A ideia central

Codigo profissional nao e apenas codigo que funciona. Ele tambem revela padroes. Se varios elementos tem a mesma aparencia, eles devem compartilhar a mesma classe. Se varias secoes tem o mesmo cabecalho, elas devem usar a mesma estrutura. Se varios espacamentos se repetem, eles podem virar utilitarios.

Pense assim: primeiro voce faz funcionar. Depois voce observa o que se repete. O CSS mais profissional nasce desse segundo olhar.
