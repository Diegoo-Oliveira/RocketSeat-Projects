Voltar para CSS Profissional Padroes

Padroes que deixam o CSS mais limpo

Um layout fica mais profissional quando voce para de criar uma regra para cada elemento e comeca a criar regras para comportamentos que se repetem.

1

Tokens globais

Cores, fontes e tamanhos principais ficam no :root. Assim o projeto tem uma fonte de verdade para o visual. 

:root {
  --brand-color-dark: #1d4ed8;
  --text-color-primary: #f1f5f9;
  --font-family: "Archivo", sans-serif;
  --h1: 800 24px/135% var(--font-family);
}
2

Utilitarios pequenos

Classes pequenas reaproveitam decisoes frequentes: grid, gap, colunas e tamanhos de texto. 

.grid { display: grid; }
.grid-flow-col { grid-auto-flow: column; }
.gap-16 { gap: 16px; }
.text-xl { font: var(--h2); }
3

Componentes reutilizaveis

Se varios elementos tem a mesma aparencia, crie uma classe de componente. 

.content-tag {
  display: inline-block;
  padding: 4px 8px;
  border-radius: 4px;
  text-transform: uppercase;
}
4

Layout por areas

Em paginas grandes, grid-template-areas deixa claro o mapa da tela. 

main {
  display: grid;
  grid-template-areas:
    "featured featured"
    "weekly weekly"
    "ai aside";
}

Escopo por contexto

Outra diferenca importante e agrupar regras que pertencem a mesma secao. Em vez de espalhar estilos da area destaque pelo arquivo todo, voce coloca tudo dentro do bloco dela. 

#featured {
  grid-area: featured;

  img {
    height: 100%;
    object-fit: cover;
  }

  .card {
    position: relative;
    overflow: hidden;
  }

  figcaption {
    position: absolute;
    bottom: 0;
  }
}

Esse estilo usa aninhamento de CSS. A leitura fica: dentro de #featured, estilize as imagens, os cards e o caption.
