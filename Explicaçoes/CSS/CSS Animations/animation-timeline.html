animation-timeline e Funções de Timing

Com animation-timeline voce pode vincular o progresso de uma animacao ao scroll da pagina ou a visibilidade de um elemento — sem uma linha de JavaScript. Junto disso, as funções de timing (steps(), cubic-bezier() e a moderna linear()) definem exatamente o ritmo do movimento.

O que é animation-timeline

Por padrao, uma animacao CSS avanca no tempo (usando animation-duration). Com animation-timeline voce troca esse eixo: o progresso pode ser controlado pelo scroll do usuario ou pela posicao de um elemento na viewport. 

/* Valor padrao — avanca no tempo */
animation-timeline: auto;

/* Scroll do documento inteiro */
animation-timeline: scroll();

/* Posicao de um elemento especifico na tela */
animation-timeline: view();

/* Named scroll timeline (criada com @scroll-timeline) */
animation-timeline: --minha-timeline;

Scroll-driven animations fazem parte da especificacao CSS Animations Level 2. Chrome e Edge ≥ 115 suportam sem flag. Firefox e Safari ainda tem suporte parcial.

Chrome 115+ Edge 115+ Firefox (flag) Safari 18+

Os tres tipos de timeline

Tipo Sintaxe Quando usar
auto auto Padrao — animacao baseada em tempo
scroll() scroll(root block) Progresso igual ao scroll do container
view() view(block) Baseado na visibilidade do elemento 
/* scroll() — argumentos */
scroll()            /* scroller mais proximo, eixo block */
scroll(root)        /* usa o viewport (pagina toda) */
scroll(root inline) /* eixo horizontal */
scroll(nearest)     /* container overflow mais proximo */

/* view() — argumentos */
view()              /* eixo block, inset 0 */
view(inline)        /* eixo horizontal */
view(block 10%)     /* com margem de 10% dos dois lados */

scroll() ao vivo — barra de progresso scroll-driven

Role dentro da caixa abaixo. A barra roxa no topo avanca de 0% a 100% conforme o scroll. Isso e feito com zero JavaScript:

role dentro da caixa →
↓ role para ver os itens aparecerem
📌 Item 1 — animation-timeline: scroll()
🎨 Item 2 — progresso sem JavaScript
⚡ Item 3 — animation-range: entry 0% entry 60%
🌀 Item 4 — vinculado ao scroll do container
✅ Item 5 — funciona so com CSS!

Codigo do exemplo

<!-- HTML — container com overflow-y: scroll -->
<div class="scroll-container">
  <div class="progress-bar"></div>

  <div class="item">Item 1</div>
  <div class="item">Item 2</div>
</div>
/* CSS — Barra de progresso */
@keyframes scroll-progress {
  from { transform: scaleX(0); }
  to   { transform: scaleX(1); }
}

.progress-bar {
  transform-origin: left;
  animation: scroll-progress linear;
  /* aqui trocamos "auto" por scroll() */
  animation-timeline: scroll(nearest block);
}

/* CSS — Itens que aparecem ao rolar */
@keyframes reveal-item {
  from { opacity: 0; transform: translateX(-20px); }
  to   { opacity: 1; transform: translateX(0); }
}

.item {
  animation: reveal-item ease-out both;
  animation-timeline: view(nearest block);
  /* define quando no ciclo de visibilidade a animacao ocorre */
  animation-range: entry 0% entry 60%;
}

animation-range define a fatia da timeline que aciona a animacao. entry = elemento entrando na viewport, exit = saindo.

view() — o que é a "jornada de visibilidade"

Enquanto scroll() usa o quanto o container foi rolado como eixo de progresso, a view() usa a posicao do elemento em relacao ao viewport. O progresso vai de 0% (elemento totalmente fora, entrando) ate 100% (elemento totalmente fora, saindo). 

/* A jornada completa de um elemento com view() */

 0%  — elemento começa a entrar na viewport (borda inferior)
       ↓ animation-range: entry
50%  — metade visivel
       ↓ animation-range: contain
75%  — completamente dentro
       ↓ animation-range: exit
100% — sai completamente pela borda superior
scroll() O eixo é o scroll do container. Todos os elementos compartilham o mesmo progresso. Bom para barras de leitura e parallax.
view() O eixo é a posicao deste elemento na viewport. Cada elemento tem seu proprio progresso. Bom para revelar conteudo ao rolar.

view() ao vivo — 5 efeitos diferentes view-driven

Role dentro da caixa. Cada cartao usa animation-timeline: view() com um animation-range diferente — observe como cada um reage de forma independente:

role para ver cada efeito →
↓ cada cartao tem seu proprio progresso
⬆️
Sobe ao entrar animation-range: entry 0% entry 70%
➡️
Desliza da direita animation-range: entry 0% entry 70%
🔍
Expande ao entrar animation-range: entry 0% entry 65%
✨
Brilha enquanto visivel animation-range: contain 0% contain 100%
🔄
Gira ao entrar animation-range: entry 0% entry 70%
👋
Some ao sair (role ate o fim) animation-range: exit 0% exit 80%

Codigo — view() com entry

<!-- HTML -->
<div class="card vc-up">Sobe ao entrar</div>
<div class="card vc-right">Desliza da direita</div>
<div class="card vc-exit">Some ao sair</div>
/* Efeito 1 — sobe ao entrar */
@keyframes rise {
  from { opacity: 0; transform: translateY(28px); }
  to   { opacity: 1; transform: translateY(0); }
}
.vc-up {
  animation: rise ease-out both;
  animation-timeline: view();          /* jornada deste elemento */
  animation-range: entry 0% entry 70%; /* ocorre ao entrar */
}

/* Efeito 2 — desliza da direita */
@keyframes slide-right {
  from { opacity: 0; transform: translateX(40px); }
  to   { opacity: 1; transform: translateX(0); }
}
.vc-right {
  animation: slide-right ease-out both;
  animation-timeline: view();
  animation-range: entry 0% entry 70%;
}

/* Efeito 3 — some ao sair */
@keyframes fade-exit {
  from { opacity: 1; transform: translateX(0); }
  to   { opacity: 0; transform: translateX(30px); }
}
.vc-exit {
  animation: fade-exit ease-in both;
  animation-timeline: view();
  animation-range: exit 0% exit 80%; /* ocorre ao sair */
}

view() — argumentos e inset

/* Forma basica — usa o viewport inteiro como zona */
animation-timeline: view();

/* Especificar o eixo */
animation-timeline: view(block);  /* vertical (padrao) */
animation-timeline: view(inline); /* horizontal */

/* Com inset — reduz a zona de visibilidade */
animation-timeline: view(block 100px);
/* elemento precisa estar 100px dentro da borda para
   comecar a contar como "visivel" */

animation-timeline: view(block 20%);
/* zona de visibilidade reduzida em 20% dos dois lados */

animation-timeline: view(block 80px 0px);
/* inset-top: 80px, inset-bottom: 0 */

Use inset para que a animacao comece apenas quando o elemento ja esta bem visivel na tela, evitando que ela dispare logo que um pixel entra no viewport. 

/* Exemplo pratico: só anima quando
   o elemento esta pelo menos 80px visivel */
.secao {
  animation: aparecer ease-out both;
  animation-timeline: view(block 80px);
  animation-range: entry 0% entry 100%;
}

@keyframes aparecer {
  from { opacity: 0; transform: translateY(30px); }
  to   { opacity: 1; transform: translateY(0); }
}

animation-range

Funciona junto com view() para definir em qual parte da jornada do elemento a animacao acontece:

Keyword Momento
entry Elemento entrando na viewport (de fora para dentro)
exit Elemento saindo da viewport (de dentro para fora)
contain Enquanto o elemento esta completamente visivel
cover Todo o intervalo de cobertura (entrada ate saida) 
/* Aparece conforme entra (0% a 100% da entrada) */
animation-range: entry 0% entry 100%;

/* Aparece na primeira metade da entrada */
animation-range: entry 0% entry 50%;

/* Desaparece ao sair */
animation-range: exit 0% exit 100%;

/* Shorthand de inicio e fim */
animation-range: entry exit;

Named Scroll Timeline

Voce pode criar uma timeline nomeada em um container e referenciar ela em qualquer elemento filho: 

<!-- HTML -->
<div class="wrapper">
  <div class="fill-bar"></div>
  <div class="conteudo">...</div>
</div>
/* CSS — define a timeline nomeada no container */
.wrapper {
  overflow-y: scroll;
  scroll-timeline: --progresso block;
}

/* CSS — usa a timeline nomeada no filho */
.fill-bar {
  animation: crescer linear;
  animation-timeline: --progresso;
}

@keyframes crescer {
  from { width: 0%; }
  to   { width: 100%; }
}

scroll-timeline: --nome eixo registra a timeline. Qualquer descendente pode usa-la pelo nome, sem precisar de scroll(nearest).

Funcoes de timing — visao geral

As funções de timing controlam o ritmo com que a animacao avanca entre os keyframes. Elas se aplicam tanto a animation-timing-function quanto a transition-timing-function:

Funcao Comportamento
ease Rapido no meio, lento nas pontas (padrao)
linear Velocidade constante do inicio ao fim
ease-in Comeca devagar, termina rapido
ease-out Comeca rapido, termina devagar (mais natural)
ease-in-out Lento nas duas pontas, rapido no meio
cubic-bezier() Curva totalmente personalizada
steps() Movimento em passos discretos (quadro a quadro)
linear() Curva multipontos — spring, bounce e mais

steps() — quadro a quadro

steps(n, direction) divide a animacao em n passos discretos, como os fotogramas de uma animacao tradicional. Passe o mouse para ver a diferenca:

steps(5, start)
steps(5, end)
steps(4, jump-both)
steps(6, jump-none)
step-start
step-end 
/* Sintaxe */
steps(numero-de-passos, direcao)

/* Direcoes disponiveis */
steps(5, start)      /* pula no inicio de cada passo */
steps(5, end)        /* pula no final de cada passo (padrao) */
steps(4, jump-both)  /* inclui inicio e fim */
steps(6, jump-none)  /* exclui inicio e fim */

/* Atalhos */
step-start  /* = steps(1, start) */
step-end    /* = steps(1, end) */

/* Uso classico: sprite sheet */
.sprite {
  background: url(spritesheet.png);
  animation: run 0.6s steps(8) infinite;
}
@keyframes run {
  to { background-position: -640px 0; }
}

cubic-bezier() — curva personalizada

Uma curva de Bezier cubica e definida por quatro valores: as coordenadas dos dois pontos de controle P1 e P2. Passe o mouse para ver as curvas ao vivo:

elastic (overshoot)
back overshoot
smooth (ease-out)
sharp (material)
expo out
back in

Como funciona o cubic-bezier

/* Sintaxe */
cubic-bezier(x1, y1, x2, y2)

/* Os eixos vao de 0 a 1 em X (tempo).
   Y pode ultrapassar 0–1 para overshoot! */

/* Curvas comuns e equivalencias */
ease         → cubic-bezier(0.25, 0.1, 0.25, 1)
ease-in      → cubic-bezier(0.42, 0, 1, 1)
ease-out     → cubic-bezier(0, 0, 0.58, 1)
ease-in-out  → cubic-bezier(0.42, 0, 0.58, 1)
linear       → cubic-bezier(0, 0, 1, 1)

/* Curvas populares de design */

/* Elastic — ultrapassa o destino levemente */
cubic-bezier(0.34, 1.56, 0.64, 1)

/* Overshoot duplo (spring-like) */
cubic-bezier(0.68, -0.55, 0.27, 1.55)

/* Expo out — desacelera forte no final */
cubic-bezier(0.16, 1, 0.3, 1)

/* Material Design — sharp */
cubic-bezier(0.4, 0, 0.6, 1)

Use cubic-bezier.com para editar a curva visualmente e copiar o codigo pronto.

linear() — curva multipontos CSS 2024

A funcao linear() aceita uma lista de pontos que definem a curva com precisao total. Perfeita para imitar spring physics e bounce sem bibliotecas JS. Passe o mouse para sentir a diferenca:

bounce
spring damped
ease simples

Sintaxe do linear()

/* Forma basica — pontos de 0 a 1 */
linear(0, 0.5, 1)

/* Com posicao de tempo explicita */
linear(0, 0.25 25%, 0.75 75%, 1)

/* Bounce simplificado */
transition-timing-function: linear(
  0, 0.004, 0.016, 0.035, 0.063, 0.098,
  0.141, 0.191, 0.25, 0.316, 0.391, 0.473,
  0.563, 0.66, 0.765, 0.876, 1, 0.943,
  0.891, 0.845, 0.804, 0.769, 0.739, 0.714,
  0.694, 0.678, 0.666, 0.658, 0.653, 0.651,
  /* ... mais pontos ... */
  1
);

Os pontos sao valores de output (0 = inicio, 1 = fim) interpolados linearmente entre si. Quanto mais pontos, mais fiel e a curva desejada. 

/* Geradores de linear() online */
/* linear-easing.netlify.app */
/* generator.linear-easing.com */

/* Exemplo de uso em animacao */
.card {
  animation: enter 0.9s forwards;
  animation-timing-function: linear(
    0, 0.25 25%, 0.75 75%, 1
  );
}
@keyframes enter {
  from { opacity: 0; transform: translateY(30px); }
  to   { opacity: 1; transform: translateY(0); }
}

Suporte: Chrome 113+, Edge 113+, Firefox 112+, Safari 17.2+. Ja disponivel para uso em producao!

Timing function dentro de @keyframes

Voce pode aplicar funcoes de timing diretamente em keyframes individuais. A funcao vale para o trecho que vai daquele keyframe ate o proximo: 

@keyframes exemplo {
  0% {
    transform: translateY(0);
    /* ease-in do 0% ao 50% */
    animation-timing-function: ease-in;
  }
  50% {
    transform: translateY(-80px);
    /* bounce de volta ao final */
    animation-timing-function: cubic-bezier(0.34, 1.56, 0.64, 1);
  }
  100% {
    transform: translateY(0);
  }
}

Isso permite ritmos diferentes em cada fase da animacao — acelerada na subida e elastica na descida, por exemplo.

Aplicando animation-timeline na pratica

<!-- HTML — pagina com secoes -->
<header class="hero">...</header>
<section class="secao">...</section>

<!-- barra de leitura no topo -->
<div class="reading-bar"></div>
/* CSS — Barra de leitura da pagina inteira */
@keyframes leitura {
  from { transform: scaleX(0); }
  to   { transform: scaleX(1); }
}

.reading-bar {
  position: fixed;
  top: 0;
  left: 0;
  right: 0;
  height: 4px;
  background: linear-gradient(90deg, #e11d48, #7c3aed);
  transform-origin: left;

  /* Vincula ao scroll do documento */
  animation: leitura linear;
  animation-timeline: scroll(root block);
}

/* Elemento que aparece ao entrar na tela */
.secao {
  animation: aparecer ease-out both;
  animation-timeline: view();
  animation-range: entry 0% entry 50%;
}

@keyframes aparecer {
  from { opacity: 0; transform: translateY(40px); }
  to   { opacity: 1; transform: translateY(0); }
}

Resumo rapido

  1. animation-timeline: scroll() vincula a animacao ao progresso do scroll de um container
  2. animation-timeline: view() anima com base na visibilidade do elemento na viewport
  3. animation-range delimita qual parte da timeline (entry, exit, contain, cover) aciona a animacao
  4. scroll-timeline: --nome eixo cria uma timeline nomeada para reuso em filhos
  5. steps(n) cria movimento quadro a quadro — ideal para sprites e efeitos digitais
  6. cubic-bezier(x1,y1,x2,y2) permite curvas personalizadas; Y pode passar de 1 para overshoot
  7. linear() e a funcao mais flexivel: descreve qualquer curva com uma lista de pontos, incluindo bounce e spring
  8. Timing functions podem ser declaradas dentro de keyframes individuais para ritmos diferentes em cada fase
