Transformacoes 2D

A propriedade transform permite mover, girar, redimensionar e distorcer elementos sem afetar o layout dos vizinhos. Transformacoes 2D trabalham nos eixos X (horizontal) e Y (vertical) e sao a base para quase todo movimento visual no CSS.

translate() — mover o elemento

Move o elemento ao longo dos eixos X e Y sem tirar do fluxo do documento. Os vizinhos continuam no lugar original. 

<!-- HTML -->
<div class="caixa">Mover</div>
/* CSS — Move 30px para direita e 10px para cima */
.caixa {
  width: 80px;
  height: 80px;
  background: #2563eb;
  color: #fff;
  border-radius: 14px;
  transform: translate(30px, -10px);
}

/* CSS — Funcoes separadas por eixo */
.caixa { transform: translateX(30px); }
.caixa { transform: translateY(-10px); }

/* CSS — Usando porcentagem (relativo ao proprio elemento) */
.caixa { transform: translate(50%, -50%); }
/* Muito usado para centralizar com position: absolute */

rotate() — girar o elemento

Gira o elemento em torno do seu centro (ou do ponto definido por transform-origin). Valores positivos giram no sentido horario. 

<!-- HTML -->
<div class="icone">★</div>
/* CSS — Gira 45 graus no sentido horario */
.icone {
  width: 60px;
  height: 60px;
  background: #e11d48;
  display: grid;
  place-items: center;
  transform: rotate(45deg);
}

/* CSS — Sentido anti-horario */
.icone { transform: rotate(-30deg); }

/* CSS — Unidades possiveis */
.icone { transform: rotate(0.25turn); }  /* 1/4 de volta = 90deg */
.icone { transform: rotate(100grad); }   /* 100 grads = 90deg */
.icone { transform: rotate(1.57rad); }   /* radianos */

scale() — redimensionar o elemento

Aumenta ou diminui o tamanho visual do elemento. O valor 1 e o tamanho original, 2 e o dobro, 0.5 e metade. Nao afeta o espaco que o elemento ocupa no layout. 

<!-- HTML -->
<div class="foto"></div>
<img class="avatar" src="perfil.jpg" alt="Foto" />
/* CSS — Dobra o tamanho nos dois eixos */
.foto { transform: scale(2); }

/* CSS — Largura 1.5x, altura 0.8x */
.foto { transform: scale(1.5, 0.8); }

/* CSS — Funcoes separadas por eixo */
.foto { transform: scaleX(1.5); }
.foto { transform: scaleY(0.8); }

/* CSS — Espelhar horizontalmente */
.avatar { transform: scaleX(-1); }

skew() — distorcer o elemento

Inclina o elemento ao longo dos eixos X e Y, criando um efeito de paralelogramo. Valores em graus. 

<!-- HTML -->
<div class="faixa">DESCONTO</div>
/* CSS — Inclina 15 graus no X e 5 no Y */
.faixa { transform: skew(15deg, 5deg); }

/* CSS — Funcoes separadas */
.faixa { transform: skewX(15deg); }
.faixa { transform: skewY(5deg); }

/* CSS — Efeito italico mais forte */
.faixa { transform: skewX(-10deg); }
hover para ver skew
skew

skew e menos usado que translate, rotate e scale, mas e util para efeitos decorativos em backgrounds e faixas.

Tabela resumo das funcoes 2D

Funcao O que faz Unidade
translate(x, y) Move o elemento px, %, rem, em
translateX(x) Move so no eixo X px, %, rem
translateY(y) Move so no eixo Y px, %, rem
rotate(angle) Gira o elemento deg, turn, rad, grad
scale(x, y) Redimensiona numero (1 = original)
scaleX(x) / scaleY(y) Redimensiona por eixo numero
skew(x, y) Distorce / inclina deg
skewX(x) / skewY(y) Distorce por eixo deg
matrix(a,b,c,d,tx,ty) Todas as 2D em uma so numeros

Combinando transformacoes

Voce pode aplicar varias funcoes na mesma propriedade transform, separadas por espaco. O navegador aplica da esquerda para a direita. 

<!-- HTML -->
<div class="badge">Novo</div>
/* CSS — Gira E depois escala */
.badge { transform: rotate(15deg) scale(1.2); }

/* CSS — Move E depois gira — resultado diferente! */
.badge { transform: translate(50px, 0) rotate(45deg); }

/* CSS — Gira E depois move — resultado diferente! */
.badge { transform: rotate(45deg) translate(50px, 0); }
hover para ver combinacao
combo

A ordem importa! rotate translate tem resultado diferente de translate rotate porque cada funcao cria um novo sistema de coordenadas.

transform-origin — o ponto de referencia

Por padrao, transformacoes usam o centro do elemento como ponto de referencia. Com transform-origin voce muda isso para qualquer ponto: cantos, bordas ou posicao customizada. 

<!-- HTML -->
<div class="porta">Abrir</div>
/* CSS — Padrao — centro */
.porta { transform-origin: center; }       /* 50% 50% */

/* CSS — Cantos */
.porta { transform-origin: top left; }     /* 0% 0% */
.porta { transform-origin: top right; }    /* 100% 0% */
.porta { transform-origin: bottom left; }  /* 0% 100% */
.porta { transform-origin: bottom right; } /* 100% 100% */

/* CSS — Posicao customizada */
.porta { transform-origin: 20px 40px; }
.porta { transform-origin: 30% 70%; }

matrix() — todas as 2D em uma funcao

A funcao matrix(a, b, c, d, tx, ty) e a forma unificada de expressar qualquer transformacao 2D. Ela recebe 6 parametros que combinam scale, skew e translate:

Parametro Equivalente
a scaleX
b skewY
c skewX
d scaleY
tx translateX
ty translateY 
<!-- HTML -->
<div class="elemento">M</div>
/* CSS — matrix identidade (nenhuma transformacao) */
.elemento { transform: matrix(1, 0, 0, 1, 0, 0); }

/* CSS — equivalente a scale(2) translate(30px, 10px) */
.elemento { transform: matrix(2, 0, 0, 2, 30, 10); }

Na pratica, matrix() e raramente escrita a mao. Use as funcoes individuais (translate, rotate, scale, skew) que sao muito mais legiveis. O navegador converte tudo para matrix internamente.

Propriedades individuais (CSS moderno)

O CSS moderno permite escrever translate, rotate e scale como propriedades separadas, sem usar transform: 

<!-- HTML -->
<div class="elemento">Hover</div>
/* CSS — Forma classica */
.elemento {
  transform: translate(20px, 10px) rotate(15deg) scale(1.2);
}

/* CSS — Forma moderna (propriedades individuais) */
.elemento {
  translate: 20px 10px;
  rotate: 15deg;
  scale: 1.2;
}

/* CSS — Vantagem: voce pode animar cada uma separadamente */
.elemento {
  translate: 0 0;
  rotate: 0deg;
  transition: translate 0.3s ease, rotate 0.5s ease;
}
.elemento:hover {
  translate: 20px -10px;
  rotate: 15deg;
}

As propriedades individuais sao suportadas em todos os browsers modernos (Chrome 104+, Firefox 72+, Safari 14.1+). Se precisar de suporte mais amplo, use a forma classica com transform.

Comportamentos importantes

  1. Nao afeta o layout: transform move o elemento visualmente, mas os vizinhos continuam como se ele estivesse no lugar original. Diferente de margin ou position.
  2. Cria stacking context: qualquer transform diferente de none cria um novo contexto de empilhamento. Filhos com position: fixed passam a se posicionar em relacao ao elemento transformado, nao ao viewport.
  3. GPU acceleration: transformacoes 2D (especialmente translate e scale) podem ser aceleradas pela GPU, tornando animacoes muito mais suaves que mover elementos com left/top.

Resumo rapido

  1. translate() move, rotate() gira, scale() redimensiona, skew() distorce
  2. combine varias funcoes no mesmo transform separadas por espaco
  3. a ordem das funcoes muda o resultado final
  4. transform-origin define o ponto de referencia da transformacao
  5. matrix() e a forma unificada, mas raramente escrita manualmente
  6. propriedades individuais (translate, rotate, scale) sao a forma moderna
  7. transform nao afeta o layout dos vizinhos e cria stacking context
