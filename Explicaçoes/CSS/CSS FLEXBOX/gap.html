Voltar para o indice gap

gap

gap cria espaco entre os itens de um container flex sem precisar colocar margem em cada filho. E uma forma simples e limpa de controlar respiro entre colunas e linhas. 

.container {
  display: flex;
  gap: 16px;
}

Sem gap

Os blocos ficam grudados, sem espacamento definido.

gap: 0;

B
C
D

Um valor

Um unico valor serve para linha e coluna ao mesmo tempo. 

gap: 20px;
A
B
C
D

Dois valores

O primeiro valor controla a distancia entre linhas. O segundo, entre colunas. 

gap: 12px 28px;

Dica pratica: prefira gap para organizar espacos internos do Flexbox. Use margem nos filhos apenas quando o espaco precisar existir fora daquele grupo.
