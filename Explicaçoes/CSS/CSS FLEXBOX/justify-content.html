Voltar para o indice justify-content

justify-content

justify-content alinha os itens no eixo principal. Se a direcao for row, ele age na horizontal. Se a direcao for column, ele age na vertical. 

.container {
  display: flex;
  justify-content: center;
}

flex-start

Os itens comecam no inicio do eixo principal.

justify-content: flex-start;
1
2
3

center

Todo o grupo vai para o centro do eixo principal.

justify-content: center;
1
2
3

space-between

O primeiro item encosta no inicio, o ultimo vai para o fim e o espaco restante e distribuido no meio. 

justify-content: space-between;
1
2
3

space-evenly

O espaco fica igual entre os itens e tambem nas bordas do container. 

justify-content: space-evenly;
1
2
3

Para memorizar: justify-content cuida da distribuicao do grupo inteiro no eixo principal.
