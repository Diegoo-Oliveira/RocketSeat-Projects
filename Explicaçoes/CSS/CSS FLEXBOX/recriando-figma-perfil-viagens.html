Como recriar a pagina do node 3:376

Agora sim estamos olhando para a tela certa: a pagina interna do perfil no Travelgram, com cabecalho, bloco do usuario, grade de imagens e rodape. Esta explicacao foi montada com base na captura que voce enviou do node 3:376.

O ponto principal aqui e este: quase toda a pagina pode ser pensada com Flexbox, mas a grade de fotos fica bem melhor com Grid. Entender essa divisao faz a recriacao ficar muito mais proxima do Figma.

As linhas azuis vistas no print sao marcacoes do editor do Figma sobre o bloco de nome e descricao. Elas nao fazem parte da interface final, entao a recriacao abaixo considera a tela pronta.

Leitura correta do print

  1. nav branco com logo a esquerda e menu discreto a direita
  2. faixa de perfil em cinza claro com avatar, nome, bio e dados
  3. galeria com 12 fotos em 4 colunas
  4. rodape simples com copyright e links

Essa e a pagina interna do perfil. Nao e a capa do projeto, nem uma secao isolada.

O que entrou no seu Travelgram agora

No projeto real, voce separou o CSS por responsabilidade. Isso e bom porque cada arquivo cuida de uma parte da tela e fica mais facil encontrar onde mexer.

  1. global.css: reset, variaveis, fonte, cores e classes globais
  2. styles/index.css: arquivo que importa todos os outros CSS
  3. nav.css: estilos da navegacao superior
  4. header.css: bloco de perfil com avatar, texto e informacoes
  5. main.css: galeria de fotos com Flexbox e quebra de linha
  6. footer.css: rodape com links empurrados para a direita
@import url(../global.css);
@import url(nav.css);
@import url(header.css);
@import url(main.css);
@import url(footer.css);

Repare no ../global.css: como o index.css esta dentro da pasta styles, o ../ sobe uma pasta para encontrar o arquivo global.

Quando usar nav

Use nav quando o bloco representa navegacao da pagina: logo clicavel, menu, links principais, busca ou atalhos de rota. 

<nav class="container">
  <a href="#" id="logo">...</a>
  <ul id="first-menu">...</ul>
</nav>

No Travelgram, o topo e navegacao de verdade, por isso nav faz mais sentido que uma div solta.

Quando usar div

Use div quando voce so precisa agrupar elementos para layout ou aparencia, sem dar um significado especial para o navegador. 

<div class="bg-surface-color">
  <nav class="container">...</nav>
  <header>...</header>
</div>

Aqui a div serve como faixa de fundo cinza. Ela nao e menu, nao e rodape e nao e conteudo principal: e so um agrupador.

ul, li e a no menu

Menu normalmente e uma lista de opcoes. Por isso o conjunto ul, li e a combina bem. 

<ul id="first-menu">
  <li><a href="#">Explorer</a></li>
  <li><a href="#">Minhas viagens</a></li>
</ul>

Use a para itens clicaveis. Use p quando for apenas texto comum.

container

A classe container limita a largura da pagina e cria respiro lateral. Assim o conteudo nao fica colado nas bordas. 

.container {
  padding-inline: 32px;
  max-width: 1280px;
  margin-inline: auto;
}

Voce reutilizou essa classe no nav, no header, no main e no footer.

header, main e footer

Essas tags deixam a estrutura mais clara. O header apresenta o perfil, o main guarda o conteudo principal e o footer fecha a pagina. 

<header>perfil da Isabela</header>
<main class="container">galeria de fotos</main>
<footer class="container">links finais</footer>

A tag certa ajuda voce a entender a pagina antes mesmo de olhar o CSS.

Gap e filhos diretos

O gap so cria espaco entre filhos diretos do elemento que recebeu display: flex ou display: grid. 

#info {
  display: flex;
  flex-direction: column;
  gap: 16px;
}

Por isso o id="info" precisa ficar na ul, porque os li sao os itens que voce quer separar.

1. Estrutura geral da pagina

Essa tela e uma pagina interna de perfil. Se voce quebrar o layout em blocos, ela fica assim:

  1. nav superior com marca e menu
  2. header com avatar, bio e estatisticas
  3. main com 12 imagens

<div class="bg-surface-color">
  <nav class="container">...</nav>
  <header>...</header>
</div>

<main class="container">...</main>
<footer class="container">...</footer>

Quando voce enxerga a hierarquia certa, o CSS fica muito mais simples.

2. A pagina desce em blocos

Mesmo sem colocar display: flex no body, os grandes blocos do HTML ja aparecem um abaixo do outro. O Flexbox entra dentro de cada bloco para alinhar os elementos internos. 

body
  div.bg-surface-color
    nav
    header
  main
  footer

Por isso a pagina fica naturalmente em ordem vertical: topo, perfil, galeria e rodape.

3. O nav usa Flexbox horizontal

A barra superior tem dois grupos: marca na esquerda e navegacao na direita. 

nav {
  display: flex;
  justify-content: space-between;
  align-items: center;
}

Esse e um caso classico de justify-content: space-between.

4. O bloco do perfil tambem e Flexbox

A faixa do perfil tem dois grupos principais no mesmo eixo:

  1. #profile: avatar + nome + bio
  2. #info: localizacao, paises e fotos
header .container {
  display: flex;
  justify-content: space-between;
  align-items: center;
}

#profile {
  display: flex;
  gap: 32px;
  align-items: center;
}

Aqui o Flexbox organiza tudo em linha e o gap cria respiracao entre os blocos.

O fundo mais claro dessa faixa e apenas aparencia. A organizacao do avatar, texto e dados continua sendo trabalho do Flexbox.

5. A bio empilha naturalmente

No seu CSS atual, o nome e a descricao ficam um abaixo do outro porque h1 e p ja sao elementos de bloco. Voce so precisou ajustar largura e margem. 

#profile > div {
  max-width: 384px;
}

#profile h1 {
  margin-bottom: 8px;
}

Se um dia voce quiser controlar esse espacamento com Flexbox, pode colocar display: flex e flex-direction: column nesse div.

6. As estatisticas ficam em coluna

A lista da direita pode ser pensada como um pequeno menu vertical. 

#info {
  display: flex;
  flex-direction: column;
  gap: 16px;
}

Ou seja: ate dentro de um layout grande, voce vai usando Flexbox em blocos menores.

7. Galeria com Flexbox e wrap

No seu projeto atual, a galeria usa Flexbox. As imagens ficam lado a lado e, quando nao couber mais na linha, quebram para a proxima. 

main {
  display: flex;
  flex-wrap: wrap;
  gap: 24px;
}

main img {
  width: 286px;
  height: 286px;
  object-fit: cover;
}

O flex-wrap: wrap libera a quebra de linha. O gap cria o espaco entre as fotos e o object-fit: cover faz a imagem preencher o quadrado sem distorcer.

Para copiar uma grade perfeitamente regular do Figma, Grid tambem seria uma boa escolha. Para praticar Flexbox, sua solucao com flex-wrap esta no caminho certo.

8. Rodape com margin-right auto

No rodape, voce usou Flexbox com gap. Depois, aplicou margin-right: auto no primeiro texto para empurrar os links para a direita. 

footer {
  display: flex;
  gap: 24px;
}

footer span:nth-child(1) {
  margin-right: auto;
}

Esse truque funciona porque margem automatica ocupa o espaco livre disponivel no eixo principal do Flexbox.
