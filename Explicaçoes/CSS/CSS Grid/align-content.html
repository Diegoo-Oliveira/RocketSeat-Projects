Alinhamentos content

align-content e justify-content distribuem a grade inteira dentro do container. Eles aparecem melhor quando o container e maior que a grade.

Exemplo visual

A grade pequena foi centralizada dentro de uma area maior.

Codigo

.container {
  display: grid;
  grid-template-columns: repeat(3, 72px);
  grid-template-rows: repeat(2, 58px);
  align-content: center;
  justify-content: center;
}

align-content mexe no eixo vertical. justify-content mexe no eixo horizontal.
