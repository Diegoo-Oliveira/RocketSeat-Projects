Voltar para Grid Espacamento

Gap

gap cria espaco entre as celulas da grade. Ele substitui a necessidade de colocar margem em cada item.

Exemplo visual

Aqui a distancia entre linhas e maior que a distancia entre colunas.

1
2
3
4
5

Codigo

.container {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 22px 10px;
}

Com dois valores, o primeiro e o espaco entre linhas e o segundo e o espaco entre colunas.
