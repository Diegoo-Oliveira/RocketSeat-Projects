Propriedades grid auto

Quando existem mais itens do que posicoes explicitas, o navegador cria linhas ou colunas automaticas. As propriedades grid-auto-rows, grid-auto-columns e grid-auto-flow controlam esse comportamento.

Exemplo visual

A grade tem tres colunas. Os itens extras criam novas linhas de 72px automaticamente.

Codigo

.container {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  grid-auto-rows: 72px;
  grid-auto-flow: row;
}

.item-largo {
  grid-column: span 2;
}

span 2 significa: ocupe duas faixas, sem precisar informar exatamente onde comeca e termina.
