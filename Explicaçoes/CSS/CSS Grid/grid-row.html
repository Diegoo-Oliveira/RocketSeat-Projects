Voltar para Grid Linhas ocupadas

Grid Row

grid-row faz o mesmo tipo de controle do grid-column, mas no eixo vertical. Ele define em qual linha horizontal o item comeca e onde termina.

Exemplo visual

O item laranja ocupa da linha 1 ate a linha 4, criando um bloco alto na lateral.

grid-row: 1 / 4
A
B
C
D
E
F

Codigo

.container {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  grid-template-rows: repeat(4, 54px);
}

.card-alto {
  grid-row: 1 / 4;
}

Use grid-row quando um card precisa ficar mais alto que os vizinhos.
