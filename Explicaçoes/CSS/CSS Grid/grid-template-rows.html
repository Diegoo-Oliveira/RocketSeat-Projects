Grid Template Rows

grid-template-rows define a altura das linhas explicitas da grade. Pense como se voce desenhasse prateleiras: cada valor cria uma linha com uma altura diferente.

Exemplo visual

A primeira linha tem 48px, a segunda e maior com 92px, e a terceira tem 64px.

48px
92px
64px

Codigo

.container {
  display: grid;
  grid-template-rows: 48px 92px 64px;
}

Cada valor representa uma linha. Tres valores criam tres linhas explicitas.

Quando usar

  1. quando voce quer controlar a altura de faixas de uma pagina
  2. quando um layout tem topo, conteudo e rodape com alturas previstas
  3. quando cards precisam seguir uma proporcao vertical organizada
