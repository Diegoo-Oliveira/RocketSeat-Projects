Voltar para Grid Shorthand

Shorthand grid-template

grid-template e um atalho para declarar areas, alturas de linhas e larguras de colunas em um unico bloco.

Exemplo visual

brand
menu
hero
card
aside

Codigo

.container {
  display: grid;
  grid-template:
    "brand menu" 58px
    "hero hero" 120px
    "card aside" 80px
    / 1.2fr 0.8fr;
}

O que vem depois da barra / define as colunas. Antes dela ficam as areas e as alturas das linhas.
