Voltar para CSS Profissional Comparacao

Dois codigos certos, dois niveis de organizacao

O projeto mais especifico funciona porque cada parte recebe sua regra. O projeto da Rocketseat tambem funciona, mas usa menos regras porque transforma repeticoes em padroes.

Mais especifico

Seu TechNews

Cada categoria ganhou uma classe propria, mesmo tendo quase o mesmo estilo visual. 

.content-tag-robotica { ... }
.content-tag-hologramas { ... }
.content-tag-internet { ... }
.content-tag-vestiveis { ... }

Funciona, mas cria repeticao. Se voce quiser mudar a cor das tags, precisa alterar varias classes.

Mais padronizado

Rocketseat

Uma classe unica cuida da aparencia. O texto da categoria muda no HTML, nao no CSS. 

.content-tag {
  display: inline-block;
  padding: 4px 8px;
  border-radius: 4px;
  background: var(--brand-color-dark);
}

Se mudar o visual da tag, todo o projeto acompanha a mudanca.

HTML especifico

<p class="content-tag-robotica">ROBOTICA</p>
<p class="content-tag-internet">INTERNET</p>
<p class="content-tag-ia">INTELIGENCIA ARTIFICIAL</p>

HTML padronizado

<span class="content-tag">robotica</span>
<span class="content-tag">internet</span>
<span class="content-tag">inteligencia artificial</span>

Por que o segundo parece mais profissional?

  1. Ele separa melhor conteudo e aparencia.
  2. Ele reduz repeticao de CSS.
  3. Ele cria uma linguagem visual unica para o projeto.
  4. Ele facilita manutencao: uma mudanca afeta todos os elementos parecidos.
