Voltar para CSS Profissional Refatoracao

Como transformar o CSS especifico em CSS profissional

Refatorar nao significa jogar tudo fora. O melhor caminho e trocar repeticoes por padroes aos poucos, mantendo o projeto funcionando.

Passo 1

Encontre repeticoes

Comece procurando classes que tem quase as mesmas propriedades. No TechNews, as tags de categoria sao o exemplo mais claro. 

.content-tag-robotica
.content-tag-hologramas
.content-tag-internet
.content-tag-vestiveis
Passo 2

Crie uma classe comum

Pegue o que todas tem igual e coloque em uma classe unica. 

.content-tag {
  display: inline-flex;
  align-items: center;
  width: fit-content;
  min-height: 20px;
  padding: 4px 8px;
  border-radius: 4px;
  background: var(--brand-color-dark);
  font: var(--font-tag);
}
Passo 3

Troque o HTML

Em vez de uma classe por categoria, use a mesma classe e mude o texto. 

<p class="content-tag">ROBOTICA</p>
<p class="content-tag">HOLOGRAMAS</p>
<p class="content-tag">INTERNET</p>
Passo 4

Repita com outros blocos

Depois das tags, procure cabecalhos, cards, gaps, imagens quadradas e textos que repetem comportamento. 

.section-header { ... }
.news-card { ... }
.media-square { ... }
.stack-32 { gap: 32px; }
Antes

Cabecalhos separados

#popular-heading { ... }
#featured-ia-head { ... }
#aside-head { ... }

Cada regra resolve uma secao, mas todas descrevem quase o mesmo componente: titulo da secao + link "Ver tudo".

Depois

Um componente de cabecalho

.section-header {
  display: flex;
  justify-content: space-between;
  align-items: center;
  border-top: 1px solid var(--stroke-color);
  padding-top: 12px;
}

Agora qualquer secao pode usar o mesmo padrao de cabecalho.

Ordem segura para refatorar

  1. Escolha uma repeticao pequena.
  2. Crie a classe reutilizavel.
  3. Troque apenas dois ou tres lugares no HTML.
  4. Abra no navegador e confira se nada quebrou.
  5. So depois remova as classes antigas.

O segredo e refatorar em partes pequenas. Assim voce aprende padroes sem perder o controle do layout.
