Container Queries

Container queries sao a evolucao das media queries. Em vez de perguntar "qual o tamanho da tela?", voce pergunta "qual o tamanho do pai?". Isso muda completamente como pensamos componentes reutilizaveis.

O problema que resolve

Com media queries, um card sempre muda de layout junto com a tela. Mas e se o card estiver em uma sidebar de 300px? A tela tem 1200px, entao o card recebe o layout "desktop", mas ele esta apertado em 300px de espaco. 

/* Media query: olha a tela */
@media (min-width: 768px) {
  .card { flex-direction: row; }
}
/* Problema: o card em uma sidebar estreita
   recebe layout "row" mesmo sem espaco */

/* Container query: olha o pai */
@container (min-width: 400px) {
  .card { flex-direction: row; }
}
/* Solucao: o card so muda se o pai
   tiver pelo menos 400px */

Container queries tornam componentes verdadeiramente independentes. Eles se adaptam ao espaco disponivel, nao ao tamanho da janela.

Sintaxe basica

Dois passos: (1) marcar o pai como container e (2) escrever @container no lugar de @media. 

/* Passo 1: definir o container */
.card-wrapper {
  container-type: inline-size;
  container-name: card-area;
}

/* Atalho */
.card-wrapper {
  container: card-area / inline-size;
}

/* Passo 2: usar @container */
@container card-area (min-width: 400px) {
  .card {
    display: flex;
    flex-direction: row;
    gap: 20px;
  }

  .card img {
    width: 200px;
  }
}

@container card-area (max-width: 399px) {
  .card {
    display: flex;
    flex-direction: column;
  }

  .card img {
    width: 100%;
  }
}

container-type

Valor O que faz
inline-size O container responde a largura (o mais comum)
size Responde a largura E altura
normal Nao e um container (padrao)

inline-size e o valor que voce vai usar em 99% dos casos. size adiciona contencao de altura tambem, o que pode causar problemas se o conteudo for dinamico.

Container units

Assim como vw e relativo a viewport, existem unidades relativas ao container.

Unidade Relativa a
cqw 1% da largura do container
cqh 1% da altura do container
cqi 1% do inline-size do container
cqb 1% do block-size do container
cqmin O menor entre cqi e cqb
cqmax O maior entre cqi e cqb 
.card-wrapper {
  container-type: inline-size;
}

.card h2 {
  /* Fonte que escala com o container */
  font-size: clamp(1rem, 4cqi, 2rem);
}

.card {
  padding: 3cqi;
}

cqi (container query inline) e o mais usado. Funciona como vw mas relativo ao container pai, nao a tela.

Exemplo completo

<!-- HTML -->
<div class="grid">
  <section class="card-area">
    <article class="product-card">
      <img src="produto.jpg" alt="Produto">
      <div class="info">
        <h3>Nome do produto</h3>
        <p>Descricao do produto...</p>
        <span class="price">R$ 99,90</span>
      </div>
    </article>
  </section>
</div>
/* CSS */
.card-area {
  container: product / inline-size;
}

.product-card {
  display: flex;
  flex-direction: column;
  gap: 12px;
}

.product-card img {
  width: 100%;
  border-radius: 8px;
}

/* Quando o container tiver espaco */
@container product (min-width: 500px) {
  .product-card {
    flex-direction: row;
    align-items: center;
  }

  .product-card img {
    width: 200px;
    height: 200px;
    object-fit: cover;
  }
}

@container product (min-width: 700px) {
  .product-card img {
    width: 280px;
  }

  .info h3 {
    font-size: 1.5rem;
  }
}

@media vs @container

Criterio @media @container
Referencia Viewport (tela) Container (pai)
Escopo Global Local (componente)
Reutilizacao Componente depende da tela Componente independente
Suporte Todos os navegadores Modernos (2023+)
Quando usar Layout geral da pagina Componentes reutilizaveis

Use @media para o layout macro (pagina inteira) e @container para componentes individuais. Os dois se complementam perfeitamente.

Suporte de navegadores

Container queries sao suportadas por Chrome 105+, Firefox 110+, Safari 16+ e Edge 105+. Isso cobre a grande maioria dos usuarios em 2024-2025. Para projetos que precisam de suporte a navegadores mais antigos, use media queries como fallback. 

/* Fallback com @supports */
.card-area {
  /* Navegadores antigos ignoram container */
}

@supports (container-type: inline-size) {
  .card-area {
    container: card / inline-size;
  }
}

/* Media query como fallback */
@media (max-width: 767px) {
  .product-card { flex-direction: column; }
}

/* Container query para navegadores modernos */
@container card (max-width: 400px) {
  .product-card { flex-direction: column; }
}
