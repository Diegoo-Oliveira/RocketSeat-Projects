Media Types

Antes de falar de largura de tela, o CSS permite que voce separe estilos por tipo de midia. Cada type indica para qual categoria de dispositivo ou contexto aquele CSS deve valer.

Os 4 tipos de midia

Type Para que serve Exemplo de uso
all Todos os dispositivos, sem excecao Padrao quando voce nao especifica nada
screen Telas: monitores, celulares, tablets O que voce mais usa no dia a dia
print Impressao: quando o usuario imprime a pagina Remover menu, trocar fundo para branco
speech Leitores de tela com sintetizador de voz Muito raro, quase nao usado

all e o padrao. Quando voce escreve @media (max-width: 768px) sem tipo, e o mesmo que @media all and (max-width: 768px).

Sintaxe com tipos

O media type vem antes das features, separado por and.

/* So para telas */
@media screen and (max-width: 768px) {
  .sidebar { display: none; }
}

/* So para impressao */
@media print {
  body {
    background: #ffffff;
    color: #000000;
    font-size: 12pt;
  }

  .nav, .footer, .sidebar {
    display: none;
  }

  a {
    color: #000000;
    text-decoration: underline;
  }
}

/* Para todos os tipos com uma condicao */
@media all and (min-width: 1024px) {
  .container { max-width: 1200px; }
}

Exemplo pratico: print

Quando o usuario clica em "Imprimir" (Ctrl + P), o navegador aplica os estilos do @media print. E o unico tipo, alem de screen, que voce vai usar com frequencia. 

/* Estilos normais para a tela */
.header {
  background: linear-gradient(135deg, #2563eb, #7c3aed);
  color: white;
  padding: 24px;
}

.no-print {
  /* botoes, menus, coisas interativas */
}

/* Ao imprimir: remover decoracao, economizar tinta */
@media print {
  .header {
    background: none;
    color: black;
    border-bottom: 2px solid black;
  }

  .no-print {
    display: none;
  }

  /* Mostrar URLs dos links */
  a::after {
    content: " (" attr(href) ")";
    font-size: 0.8em;
    color: #666;
  }
}

Adicionar a::after com attr(href) no print faz os links aparecerem por extenso no papel. E um padrao profissional muito valorizado.

Na tag link do HTML

Voce tambem pode usar o atributo media direto no <link> para carregar arquivos CSS diferentes para cada tipo. 

<!-- CSS para telas -->
<link rel="stylesheet"
      href="screen.css"
      media="screen">

<!-- CSS so para impressao -->
<link rel="stylesheet"
      href="print.css"
      media="print">

<!-- CSS para telas ate 768px -->
<link rel="stylesheet"
      href="mobile.css"
      media="screen and (max-width: 768px)">

O navegador baixa todos os arquivos CSS de qualquer forma, mas so aplica os que batem com a midia atual. Entao nao economiza download, mas pode ajudar na organizacao.

Types obsoletos

No passado existiam mais tipos como tv, handheld, projection e tty. Todos foram removidos do padrao moderno. 

/* ❌ Nao use mais estes tipos */
@media tv { ... }
@media handheld { ... }
@media projection { ... }
@media tty { ... }

/* ✅ Hoje so existem 4 tipos validos */
@media all { ... }
@media screen { ... }
@media print { ... }
@media speech { ... }

Se voce encontrar @media handheld em codigos antigos, saiba que navegadores modernos ignoram completamente.

Quando especificar o tipo

  1. para impressao: sempre use @media print
  2. para telas: voce pode omitir (all e o padrao)
  3. se quiser ser explicito: use screen and (...)
  4. nunca use tipos obsoletos como tv ou handheld

Na pratica, voce so vai escrever @media print e @media (max-width: ...). O tipo screen quase nunca precisa ser explicitado.

Resumo

  1. existem 4 media types: all, screen, print e speech
  2. all e o padrao quando voce nao especifica
  3. print e o unico que voce vai usar alem de screen
  4. types obsoletos (tv, handheld) devem ser ignorados
  5. o tipo vem antes das features, separado por and
