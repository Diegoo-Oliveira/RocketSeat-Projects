min-width vs max-width

Existem dois jeitos de pensar responsividade: comecar pelo celular e ir crescendo (mobile-first) ou comecar pelo desktop e ir encolhendo (desktop-first). A diferenca esta em usar min-width ou max-width.

Mobile-first (min-width)

Voce escreve o CSS base pensando no celular. Depois usa min-width para adicionar regras quando a tela for maior que o valor. 

/* Base: celular (tela pequena) */
.container {
  display: flex;
  flex-direction: column;
  padding: 16px;
}

/* A partir de 768px: tablet */
@media (min-width: 768px) {
  .container {
    flex-direction: row;
    padding: 24px;
  }
}

/* A partir de 1024px: desktop */
@media (min-width: 1024px) {
  .container {
    max-width: 1200px;
    margin: 0 auto;
    padding: 32px;
  }
}

min-width significa "a partir de". O CSS base e para telas pequenas e voce vai adicionando conforme cresce.

Desktop-first (max-width)

Voce escreve o CSS base pensando no desktop. Depois usa max-width para remover ou alterar regras quando a tela for menor que o valor. 

/* Base: desktop (tela grande) */
.container {
  display: flex;
  flex-direction: row;
  max-width: 1200px;
  margin: 0 auto;
  padding: 32px;
}

/* Ate 1023px: tablet */
@media (max-width: 1023px) {
  .container {
    padding: 24px;
  }
}

/* Ate 767px: celular */
@media (max-width: 767px) {
  .container {
    flex-direction: column;
    padding: 16px;
  }
}

max-width significa "ate". O CSS base e para telas grandes e voce vai ajustando conforme encolhe.

Comparacao visual

Mobile-first cresce de baixo para cima. Desktop-first diminui de cima para baixo.

MOBILE-FIRST 
/* base: celular */
.nav { flex-direction: column; }

@media (min-width: 768px) {
  .nav { flex-direction: row; }
}

@media (min-width: 1024px) {
  .nav { gap: 24px; }
}
DESKTOP-FIRST 
/* base: desktop */
.nav { flex-direction: row; gap: 24px; }

@media (max-width: 1023px) {
  .nav { gap: 16px; }
}

@media (max-width: 767px) {
  .nav { flex-direction: column; }
}

Qual escolher?

Criterio Mobile-first Desktop-first
Operador min-width max-width
CSS base Para celular Para desktop
Direcao Cresce adicionando Encolhe removendo
Performance Melhor em celulares Carrega CSS extra no celular
Quando usar Projetos novos Sites legados ou dashboards

A industria recomenda mobile-first como padrao. A maioria dos acessos hoje vem de celulares, entao faz sentido comecar pelo menor e ir crescendo.

Erro comum: misturar min e max

Evite misturar min-width e max-width no mesmo projeto. Isso gera conflitos dificeis de debugar. 

/* ❌ Errado: misturando estrategias */
@media (max-width: 768px) { ... }
@media (min-width: 500px) { ... }

/* ✅ Correto: escolha uma direcao */
/* Mobile-first: so min-width */
@media (min-width: 768px) { ... }
@media (min-width: 1024px) { ... }

/* OU Desktop-first: so max-width */
@media (max-width: 1023px) { ... }
@media (max-width: 767px) { ... }

Se precisar de uma faixa especifica (ex: so tablet), use and para combinar: @media (min-width: 768px) and (max-width: 1023px)

Ordem importa

No mobile-first, coloque os min-width em ordem crescente. No desktop-first, coloque os max-width em ordem decrescente. Assim a cascata funciona corretamente. 

/* Mobile-first: menor → maior */
@media (min-width: 480px) { ... }
@media (min-width: 768px) { ... }
@media (min-width: 1024px) { ... }

/* Desktop-first: maior → menor */
@media (max-width: 1023px) { ... }
@media (max-width: 767px) { ... }
@media (max-width: 479px) { ... }

Se a ordem estiver errada, um @media anterior pode ser sobrescrito por um posterior, mesmo que nao fosse a intencao.

Resumo

  1. min-width = mobile-first: CSS base pro celular, cresce
  2. max-width = desktop-first: CSS base pro desktop, encolhe
  3. nao misture os dois no mesmo projeto
  4. a ordem dos @media deve seguir a direcao escolhida
  5. mobile-first e o padrao recomendado pela industria
