Voltar para Media Queries Operadores

Operadores logicos

Operadores logicos permitem combinar varias condicoes em um unico @media. Voce pode exigir que todas sejam verdadeiras, que pelo menos uma seja, ou negar uma condicao inteira.

and – E logico

Todas as condicoes precisam ser verdadeiras. Funciona como "E isso E aquilo". 

/* Tela entre 768px e 1023px (so tablet) */
@media (min-width: 768px) and (max-width: 1023px) {
  .sidebar { width: 200px; }
}

/* Tela landscape com no minimo 600px de largura */
@media (orientation: landscape) and (min-width: 600px) {
  .gallery { grid-template-columns: repeat(3, 1fr); }
}

/* So para telas, com modo escuro, e largura minima */
@media screen and (prefers-color-scheme: dark) and (min-width: 768px) {
  .panel { background: #1e293b; }
}

Voce pode encadear quantos and quiser. Todas as condicoes devem ser verdadeiras para o bloco ser aplicado.

virgula (,) – OU logico

Basta uma das condicoes ser verdadeira. Cada trecho separado por virgula e avaliado independentemente. 

/* Celular OU impressao */
@media (max-width: 767px), print {
  .sidebar { display: none; }
}

/* Tela menor que 480px OU landscape com pouca altura */
@media (max-width: 479px),
       (orientation: landscape) and (max-height: 400px) {
  .hero {
    padding: 12px;
    font-size: 1.2rem;
  }
}

A virgula funciona como o OR. Pense: "aplique se for celular OU se estiver imprimindo".

not – negacao

Inverte toda a media query. O que era verdadeiro vira falso e vice-versa. 

/* Qualquer coisa que NAO seja print */
@media not print {
  .screen-only { display: block; }
}

/* Telas que NAO sao maiores que 1024px
   (ou seja: telas de ate 1024px) */
@media not screen and (min-width: 1025px) {
  .sidebar { display: none; }
}

not nega a media query inteira, nao so a feature. not screen and (min-width: 768px) nega tudo, nao so o min-width.

only – compatibilidade

O operador only foi criado para navegadores antigos que nao entendiam media queries. Hoje e praticamente desnecessario. 

/* Uso classico de only */
@media only screen and (max-width: 768px) {
  .mobile-menu { display: flex; }
}

/* Na pratica, e identico a: */
@media screen and (max-width: 768px) {
  .mobile-menu { display: flex; }
}

Navegadores modernos ignoram o only. Voce pode encontrar em projetos antigos, mas nao precisa usar em codigo novo.

Combinando tudo

Voce pode misturar todos os operadores para criar condicoes bem especificas. 

/* Faixa de tablet com modo escuro */
@media screen
  and (min-width: 768px)
  and (max-width: 1023px)
  and (prefers-color-scheme: dark) {
  .panel {
    background: #1e293b;
    border-color: #334155;
  }
}

/* Celular OU tablet em landscape */
@media (max-width: 479px),
       (min-width: 480px) and (max-width: 1023px)
         and (orientation: landscape) {
  .hero { padding: 16px; }
}

/* Dispositivos que tem hover E modo claro */
@media (hover: hover) and (prefers-color-scheme: light) {
  .card:hover {
    background: #f0f9ff;
    transform: translateY(-2px);
  }
}

Sintaxe moderna: range

CSS Level 4 introduziu uma sintaxe mais legivel usando <, > e <=. Suportada na maioria dos navegadores modernos. 

/* Antigo (Level 3) */
@media (min-width: 768px) and (max-width: 1023px) {
  ...
}

/* Moderno (Level 4 range) */
@media (768px <= width <= 1023px) {
  ...
}

/* Outros exemplos de range */
@media (width >= 1024px) {
  /* desktop */
}

@media (width < 768px) {
  /* celular */
}

@media (400px <= width < 900px) {
  /* faixa customizada */
}

A sintaxe de range e mais facil de ler, mas ainda nao e suportada por todos os navegadores. Verifique no caniuse.com antes de usar em producao.
