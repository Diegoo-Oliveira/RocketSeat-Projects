Voltar para Media Queries Pratica

Responsividade na pratica

Agora que voce conhece a teoria, vamos aplicar tudo em exemplos reais: adaptar grids, sidebars, fontes, navegacao e layouts completos para celular, tablet e desktop.

Exemplo 1: Grid responsivo

Um grid que vai de 3 colunas no desktop para 2 no tablet e 1 no celular. 

.cards {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 20px;
}

@media (max-width: 1023px) {
  .cards {
    grid-template-columns: repeat(2, 1fr);
  }
}

@media (max-width: 639px) {
  .cards {
    grid-template-columns: 1fr;
  }
}

Exemplo 2: Sidebar que vira topo

No desktop a sidebar fica ao lado. No celular ela vira um bloco acima do conteudo.

Exemplo 3: Navegacao responsiva

No desktop os links ficam em linha. No celular viram um menu vertical (hamburguer simplificado com CSS puro). 

.nav {
  display: flex;
  align-items: center;
  gap: 24px;
}

.nav-links {
  display: flex;
  gap: 16px;
}

.menu-toggle {
  display: none;
}

@media (max-width: 767px) {
  .nav {
    flex-wrap: wrap;
  }

  .nav-links {
    width: 100%;
    flex-direction: column;
    gap: 8px;
    display: none;  /* esconde por padrao */
  }

  .nav-links.open {
    display: flex;  /* mostra quando abrir */
  }

  .menu-toggle {
    display: block;
    margin-left: auto;
  }
}

Para um menu hamburguer completo voce precisa de JavaScript para alternar a classe .open. Mas o CSS sozinho ja cuida de toda a adaptacao visual.

Exemplo 4: Tipografia responsiva

Fontes que se adaptam ao tamanho da tela usando media queries e a funcao clamp(). 

/* Metodo 1: Media queries tradicionais */
h1 { font-size: 3rem; }

@media (max-width: 1023px) {
  h1 { font-size: 2.4rem; }
}

@media (max-width: 639px) {
  h1 { font-size: 1.8rem; }
}

/* Metodo 2: clamp() (sem media query!) */
h1 {
  font-size: clamp(1.8rem, 5vw, 3rem);
  /* minimo: 1.8rem
     ideal: 5% da viewport
     maximo: 3rem */
}

/* Metodo 3: combinando os dois */
h1 {
  font-size: clamp(1.8rem, 5vw, 3rem);
}

@media (max-width: 479px) {
  h1 {
    font-size: 1.5rem; /* garante legibilidade */
    line-height: 1.2;
  }
}

clamp() substitui muitas media queries de tipografia. Use media queries so para ajustes que clamp nao resolve, como mudar o line-height.

Exemplo 5: Imagens responsivas

/* Imagem fluida basica */
img {
  max-width: 100%;
  height: auto;
}

/* Imagens diferentes por tamanho de tela */
.hero-bg {
  background-image: url('hero-desktop.jpg');
  background-size: cover;
}

@media (max-width: 1023px) {
  .hero-bg {
    background-image: url('hero-tablet.jpg');
  }
}

@media (max-width: 639px) {
  .hero-bg {
    background-image: url('hero-mobile.jpg');
  }
}

Exemplo 6: Espaçamentos e padding

.section {
  padding: 64px 40px;
}

.container {
  max-width: 1200px;
  margin: 0 auto;
}

@media (max-width: 1023px) {
  .section {
    padding: 48px 28px;
  }
}

@media (max-width: 639px) {
  .section {
    padding: 32px 16px;
  }

  .container {
    /* no celular, usa toda a largura */
    max-width: 100%;
  }
}

/* Truque com clamp para padding fluido */
.section-fluid {
  padding: clamp(24px, 5vw, 64px)
           clamp(16px, 4vw, 40px);
}

Reduzir padding em telas menores e essencial. Cada pixel conta num celular com 375px de largura.

Checklist de responsividade

  1. meta viewport no HTML: <meta name="viewport" content="width=device-width, initial-scale=1.0">
  2. imagens com max-width: 100%
  3. fontes com clamp() ou media queries
  4. grids que reduzem colunas em telas menores
  5. sidebar que empilha verticalmente
  6. navegacao que se adapta ou vira menu
  7. paddings e margins que diminuem em mobile
  8. testar em pelo menos 3 larguras: 375px, 768px e 1280px
