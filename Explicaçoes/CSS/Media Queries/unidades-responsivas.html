Voltar para Media Queries Unidades

Unidades responsivas

Media queries controlam quando o layout muda. Unidades responsivas controlam como os elementos se adaptam. Juntas, formam a base completa da responsividade.

Unidades relativas

Unidade Relativa a Exemplo
% Tamanho do pai width: 50% = metade do pai
em Font-size do elemento pai padding: 2em = 2x a fonte do pai
rem Font-size do root (html) font-size: 1.5rem = 1.5x a fonte base
vw 1% da largura da viewport width: 80vw = 80% da tela
vh 1% da altura da viewport height: 100vh = tela inteira
vmin 1% da menor dimensao Util para manter proporcao
vmax 1% da maior dimensao Util em landscape
ch Largura do caractere "0" max-width: 72ch = ~72 caracteres

rem vs em vs px

/* px: fixo, nao escala */
h1 { font-size: 48px; }

/* rem: relativo ao root, consistente */
h1 { font-size: 3rem; }
/* Se html font-size = 16px → 3rem = 48px */
/* Se usuario mudar para 20px → 3rem = 60px */

/* em: relativo ao pai, pode "compor" */
.parent { font-size: 20px; }
.child  { font-size: 1.5em; }
/* .child = 20 × 1.5 = 30px */

.child .grandchild { font-size: 1.5em; }
/* .grandchild = 30 × 1.5 = 45px ← acumula! */

em acumula com o pai. Se o pai tem 1.2em e o filho tem 1.2em, o resultado e 1.44x a fonte do avo. Use rem para evitar esse efeito cascata.

Viewport units: vw e vh

/* Hero que ocupa a tela inteira */
.hero {
  width: 100vw;
  height: 100vh;
}

/* Fonte que cresce com a tela */
h1 {
  font-size: 5vw;
  /* Em 1200px de tela → 60px
     Em 375px de tela → 18.75px */
}

/* Cuidado: vw puro fica muito pequeno em mobile
   e muito grande em desktop.
   Solucao: usar clamp() */

100vh em celulares pode incluir a barra do navegador. Use 100dvh (dynamic viewport height) para evitar esse problema em navegadores modernos.

clamp(), min() e max()

Funcoes CSS que criam valores fluidos sem media queries. 

/* clamp(minimo, ideal, maximo) */
h1 {
  font-size: clamp(1.8rem, 5vw, 4rem);
  /* Nunca menor que 1.8rem
     Escala com 5vw
     Nunca maior que 4rem */
}

/* Padding fluido */
.section {
  padding: clamp(20px, 5vw, 64px);
}

/* Largura responsiva */
.container {
  width: min(1200px, 100% - 32px);
  /* O menor entre 1200px e (100% - 32px) */
}

/* max() para garantir minimo */
.sidebar {
  width: max(250px, 25%);
  /* O maior entre 250px e 25% */
}

clamp() e extremamente poderoso. Um unico valor substitui 2 ou 3 media queries inteiras para tipografia e espacamentos.

Combinando com media queries

/* Base responsiva com clamp() */
.container {
  width: min(1200px, calc(100% - 32px));
  margin: 0 auto;
  padding: clamp(20px, 4vw, 48px);
}

h1 {
  font-size: clamp(2rem, 6vw, 4.5rem);
}

/* Ajustes finos com media queries */
@media (max-width: 639px) {
  .container {
    /* no celular, reduzir margem lateral */
    width: calc(100% - 16px);
  }

  h1 {
    /* no celular, forcar line-height maior */
    line-height: 1.15;
    letter-spacing: -0.02em;
  }
}

@media (min-width: 1440px) {
  .container {
    /* em monitores grandes, centralizar mais */
    max-width: 1400px;
  }
}

Use clamp() para a fluidez geral e media queries para ajustes pontuais que a funcao nao resolve.

Tabela de decisao

Situacao Usar
Fonte que escala suavemente clamp(min, ideal, max)
Largura maxima de container min(1200px, 100% - 32px)
Mudar layout de colunas para linhas @media (max-width: ...)
Esconder/mostrar elementos @media com display: none
Padding/margin fluidos clamp() ou %
Imagem de fundo diferente @media com background-image
Grid automatico repeat(auto-fit, minmax(...))

repeat(auto-fit, minmax(250px, 1fr)) cria um grid responsivo sem nenhuma media query. O navegador calcula quantas colunas cabem automaticamente.

Resumo

  1. use rem para fontes e espacamentos previsíveis
  2. use % e vw/vh para dimensoes fluidas
  3. clamp() substitui muitas media queries de tipografia
  4. min() e otimo para containers com largura maxima
  5. combine clamp() com media queries para ajustes finos
  6. auto-fit + minmax() = grid responsivo sem @media
