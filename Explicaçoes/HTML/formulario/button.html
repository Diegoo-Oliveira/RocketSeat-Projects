Voltar para formularios Button

Button

button cria uma acao clicavel. Dentro de formulario, o atributo type e essencial porque muda o comportamento do botao.

Funcoes principais

  • type="submit" envia o formulario.
  • type="button" cria um botao sem acao automatica.
  • type="reset" limpa os campos do formulario.

Exemplo visual

HTML

<button type="submit">Enviar</button>
<button type="button">Salvar rascunho</button>
<button type="reset">Limpar</button>

CSS

button {
  padding: 10px 14px;
  border: 0;
  border-radius: 10px;
  background: #0f766e;
  color: white;
  font-weight: 700;
}

Sempre defina o type. Sem ele, o botao dentro de um formulario costuma agir como submit.
