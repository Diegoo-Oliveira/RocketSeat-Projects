Input Color

input type="color" abre um seletor de cor. O valor enviado costuma ser hexadecimal, como #0f766e.

Funcoes principais

  • value define a cor inicial.
  • O navegador mostra uma interface propria de escolha de cor.
  • Serve bem para temas, preferencias e personalizacao visual.

Exemplo visual

HTML

<label for="cor">Cor do tema</label>
<input id="cor" name="cor" type="color" value="#0f766e" />

CSS

input[type="color"] {
  width: 72px;
  height: 48px;
  padding: 4px;
  border-radius: 12px;
}
