Input File

input type="file" permite selecionar arquivos do dispositivo. Ele e usado para fotos, documentos, curriculos e anexos.

Funcoes principais

  • accept sugere quais formatos podem ser escolhidos.
  • multiple permite selecionar mais de um arquivo.
  • O CSS do botao nativo varia bastante entre navegadores.

Exemplo visual

Aceita PDF, PNG ou JPG.

HTML

<form enctype="multipart/form-data">
  <label for="arquivo">Anexo</label>
  <input
    id="arquivo"
    name="arquivo"
    type="file"
    accept=".pdf,.png,.jpg"
  />
</form>
