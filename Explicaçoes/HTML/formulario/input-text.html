Input Text

input type="text" e o campo basico de uma linha. Ele e usado para nome, cidade, titulo, usuario e respostas curtas.

Funcoes principais

  • name da nome ao dado enviado.
  • placeholder mostra uma dica temporaria.
  • required obriga o preenchimento.
  • maxlength limita a quantidade de caracteres.

Exemplo visual

Use ate 60 caracteres.

HTML

<label for="nome">Nome completo</label>
<input
  id="nome"
  name="nome"
  type="text"
  placeholder="Digite seu nome"
  maxlength="60"
  required
/>

CSS

input[type="text"] {
  width: 100%;
  padding: 10px 12px;
  border: 1px solid #cbd5e1;
  border-radius: 10px;
}
