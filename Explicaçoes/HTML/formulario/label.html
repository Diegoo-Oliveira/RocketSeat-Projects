Voltar para formularios Label

Label

label e o texto que identifica um campo. Quando ele esta conectado ao input, clicar no texto tambem foca ou marca o campo.

Funcoes principais

  • for no label aponta para o id do campo.
  • Melhora acessibilidade para leitores de tela.
  • Aumenta a area clicavel de checkbox e radio.

Exemplo visual

HTML

<label for="usuario">Usuario</label>
<input id="usuario" name="usuario" type="text" />

<label>
  <input type="checkbox" name="noticias" />
  Quero receber novidades
</label>

CSS

label {
  color: #162033;
  font-weight: 700;
}
