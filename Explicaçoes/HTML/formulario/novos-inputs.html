Novos Inputs

O HTML tem tipos de input que ja carregam comportamento pronto: calendarios, busca, telefone, URL, mes, semana e horario. Eles ajudam o navegador a entregar a interface mais adequada.

Tipos comuns

  • date, time, month e week lidam com datas.
  • search indica um campo de pesquisa.
  • tel melhora o teclado de telefone em celulares.
  • url valida enderecos de site.

Exemplo visual

HTML

<input type="date" name="data" />
<input type="time" name="hora" />
<input type="search" name="busca" />
<input type="tel" name="telefone" />
<input type="url" name="site" />

CSS

input {
  width: 100%;
  min-height: 44px;
  padding: 10px 12px;
  border-radius: 10px;
}

A aparencia de calendarios e seletores pode mudar entre navegadores, porque parte da interface e nativa.
