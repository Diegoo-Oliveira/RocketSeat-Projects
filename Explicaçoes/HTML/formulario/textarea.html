Textarea

textarea e o campo para textos longos. Ele e diferente do input porque permite varias linhas e pode ser redimensionado.

Funcoes principais

  • rows sugere a altura inicial em linhas.
  • maxlength limita o tamanho do texto.
  • placeholder mostra uma dica dentro do campo.

Exemplo visual

Limite de 300 caracteres.

HTML

<label for="mensagem">Mensagem</label>
<textarea
  id="mensagem"
  name="mensagem"
  rows="5"
  maxlength="300"
  placeholder="Escreva sua mensagem"
></textarea>

CSS

textarea {
  min-height: 132px;
  padding: 10px 12px;
  resize: vertical;
  border-radius: 10px;
}

resize: vertical permite aumentar a altura sem quebrar a largura do layout.
