O que sao variaveis?

Uma variavel e um nome que aponta para um valor. Pense nela como uma etiqueta em uma caixa: a etiqueta ajuda voce a encontrar o valor depois.

let nome = "Ana";
let idade = 20;

Use variaveis quando um dado precisa ser lembrado, comparado, exibido ou transformado.

Var

var declara uma variavel com escopo de funcao ou global. Ela aparece muito em codigos antigos, mas hoje costuma ser substituida por let e const.

var mensagem = "Ola";
console.log(mensagem);

Em estudos modernos, aprenda var para ler codigos existentes, mas prefira let e const nos seus novos codigos.

Case Sensitive

JavaScript diferencia letras maiusculas e minusculas. Isso significa que nome, Nome e NOME sao identificadores diferentes.

let nome = "Ana";
let Nome = "Bruno";

console.log(nome); // Ana
console.log(Nome); // Bruno

Let

let declara uma variavel que pode receber outro valor depois. Ela respeita o bloco onde foi criada.

let contador = 1;
contador = contador + 1;

console.log(contador); // 2

Use let quando o valor realmente precisa mudar durante a execucao.

Const

const declara uma constante: o identificador nao pode ser reatribuido. Isso deixa claro que aquele nome deve continuar apontando para o mesmo valor.

const linguagem = "JavaScript";

// linguagem = "CSS"; // gera erro

Quando estiver em duvida, comece com const. Troque para let apenas se precisar reatribuir.

Compreendendo escopos

Escopo e a area onde uma variavel existe e pode ser acessada. Um bloco entre chaves cria um limite importante para let e const.

if (true) {
  const status = "ativo";
  console.log(status);
}

// console.log(status); // fora do escopo

Hoisting

Hoisting e o comportamento em que algumas declaracoes parecem ser conhecidas antes da linha onde foram escritas. Com var, a declaracao e elevada, mas o valor nao.

console.log(pontos); // undefined
var pontos = 10;

Esse comportamento e uma das razoes para preferir let e const, que tornam erros de acesso antecipado mais evidentes.

Scope

Scope e simplesmente a palavra em ingles para escopo. Em JavaScript, voce vai encontrar termos como global scope, function scope e block scope.

const global = "fora";

function exemplo() {
  const local = "dentro";
}

Nomes para variaveis

Um bom nome explica o papel do valor. Prefira nomes claros como totalDoPedido em vez de letras soltas como x.

const precoProduto = 49.9;
const quantidade = 2;
const total = precoProduto * quantidade;

Tipos de Dados

Tipo de dado e a categoria do valor. JavaScript possui tipos como string, number, boolean, undefined, null, object, symbol e bigint.

typeof "texto"; // "string"
typeof 42;      // "number"
typeof true;    // "boolean"

String

String e texto. Pode ser escrita com aspas duplas, aspas simples ou crases.

const curso = "JavaScript";
const saudacao = 'Ola';

Template Literals

Template literals usam crases e permitem encaixar valores dentro do texto com ${...}.

const nome = "Ana";
const mensagem = `Ola, ${nome}!`;

console.log(mensagem);

Number

number representa numeros inteiros e decimais. Ele e usado em contas, comparacoes e medidas.

const preco = 19.9;
const desconto = 5;
const final = preco - desconto;

Boolean

Boolean representa apenas dois estados: true ou false. E muito usado em decisoes.

const usuarioLogado = true;

if (usuarioLogado) {
  console.log("Mostrar perfil");
}

Undefined e Null

undefined aparece quando um valor ainda nao foi definido. null costuma ser usado quando voce quer marcar intencionalmente a ausencia de valor.

let resposta;
const usuario = null;

Conversao e Coercao de Tipos

Conversao e quando voce transforma um tipo de forma explicita. Coercao e quando o JavaScript tenta transformar automaticamente durante uma operacao.

Number("10"); // conversao explicita
"10" + 2;     // "102", coercao para texto
"10" - 2;     // 8, coercao para numero

Quando estiver aprendendo, prefira conversoes explicitas para deixar a intencao clara.
