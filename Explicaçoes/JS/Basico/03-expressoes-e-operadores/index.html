Expressoes e Operadores

Uma expressao e qualquer pedaco de codigo que resulta em um valor. O numero 2, a conta 2 + 3 e a chamada nome.toUpperCase() sao expressoes.

const total = 10 + 5;
const mensagem = "Total: " + total;

Operadores Aritmeticos

Servem para fazer contas: soma, subtracao, multiplicacao, divisao, resto da divisao e exponenciacao.

10 + 2; // 12
10 - 2; // 8
10 * 2; // 20
10 / 2; // 5
10 % 3; // 1
2 ** 3; // 8

Incremento e Decremento

++ aumenta um valor em 1. -- diminui um valor em 1.

let passos = 0;
passos++;
passos--;

console.log(passos); // 0

Eles sao comuns em contadores, mas escreva com clareza quando estiver aprendendo.

Ordem de Precedencia

Precedencia define qual operador e resolvido primeiro. Multiplicacao costuma acontecer antes da soma.

const resultado = 2 + 3 * 4;
console.log(resultado); // 14

Grouping Operator

Parenteses mudam a ordem de avaliacao e deixam a intencao mais clara.

const resultado = (2 + 3) * 4;
console.log(resultado); // 20

Igual a e Diferente de

== e != comparam valores permitindo conversao automatica de tipo. Isso pode causar surpresas.

"5" == 5;  // true
"5" != 5;  // false

Estritamente Igual e Diferente

=== e !== comparam valor e tipo. Na maioria dos casos, eles sao a escolha mais segura.

"5" === 5; // false
"5" !== 5; // true

Use comparacao estrita para evitar coercao inesperada.

Maior, Menor e Igual

Esses operadores comparam grandezas e retornam true ou false.

10 > 5;  // true
10 < 5;  // false
10 >= 10; // true
7 <= 4;  // false

Operadores de Atribuicao

Atribuicao coloca um valor em uma variavel. Alguns atalhos fazem conta e atribuicao ao mesmo tempo.

let pontos = 10;
pontos += 5; // pontos = pontos + 5
pontos -= 2; // pontos = pontos - 2

Operadores Logicos

&& significa "e", || significa "ou" e ! inverte um valor booleano.

const temEmail = true;
const temSenha = true;

if (temEmail && temSenha) {
  console.log("Pode entrar");
}
