Condicionais

Condicionais fazem o codigo tomar decisoes. Se uma condicao for verdadeira, um bloco roda; se nao for, outro caminho pode acontecer.

const idade = 18;

if (idade >= 18) {
  console.log("Maior de idade");
}

Operador Condicional Ternario

O ternario e uma forma curta de escolher entre dois valores. Ele tem tres partes: condicao, valor se verdadeiro e valor se falso.

const idade = 17;
const mensagem = idade >= 18 ? "Pode entrar" : "Nao pode entrar";

Use ternario para escolhas simples. Para regras longas, prefira if e else.

Falsy e Truthy

Em contextos de decisao, JavaScript converte valores para booleanos. Valores como false, 0, "", null, undefined e NaN sao falsy. Muitos outros valores sao truthy.

const nome = "";

if (nome) {
  console.log("Tem nome");
} else {
  console.log("Nome vazio");
}

If

if executa um bloco somente quando a condicao e verdadeira.

const saldo = 100;

if (saldo > 0) {
  console.log("Saldo disponivel");
}

If Else

else define o caminho alternativo quando o if nao passa.

const aprovado = false;

if (aprovado) {
  console.log("Parabens");
} else {
  console.log("Tente novamente");
}

Else if

else if permite testar mais de uma possibilidade em sequencia.

const nota = 7;

if (nota >= 9) {
  console.log("Excelente");
} else if (nota >= 6) {
  console.log("Aprovado");
} else {
  console.log("Revisar conteudo");
}

Switch

switch compara um valor com varias possibilidades. Ele ajuda quando voce tem muitos casos para o mesmo dado.

const dia = "segunda";

switch (dia) {
  case "segunda":
    console.log("Comeco da semana");
    break;
  default:
    console.log("Outro dia");
}

O break evita que o codigo continue executando os proximos casos.

Tratamento de Excecoes

Excecoes sao erros que podem interromper a execucao. Tratar excecoes significa preparar uma resposta para quando algo falha.

throw new Error("Algo deu errado");

Try / Catch / Finally

try envolve o codigo que pode falhar. catch recebe o erro. finally roda no final, tendo erro ou nao.

try {
  JSON.parse("{ nome: Ana }");
} catch (erro) {
  console.log("JSON invalido");
} finally {
  console.log("Tentativa finalizada");
}
