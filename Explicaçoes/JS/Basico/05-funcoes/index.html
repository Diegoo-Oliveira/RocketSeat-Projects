O que sao funcoes?

Uma funcao e um bloco de codigo preparado para executar uma tarefa. Ela pode receber dados, processar esses dados e devolver um resultado.

function mostrarMensagem() {
  console.log("Ola!");
}

Primeira funcao

Declarar uma funcao cria a receita. Chamar a funcao executa a receita.

function saudacao() {
  console.log("Bem-vindo ao JavaScript");
}

saudacao();

Argumentos e Parametros

Parametro e o nome usado dentro da funcao. Argumento e o valor real enviado na chamada.

function cumprimentar(nome) {
  console.log(`Ola, ${nome}`);
}

cumprimentar("Ana");

nome e parametro. "Ana" e argumento.

Retornando valores

return devolve um valor para quem chamou a funcao. Depois do return, a funcao termina.

function somar(a, b) {
  return a + b;
}

const total = somar(2, 3);

Escopo de Funcao

Valores criados dentro de uma funcao ficam protegidos ali dentro, a menos que sejam retornados ou passados para fora.

function criarMensagem() {
  const texto = "Oi";
  return texto;
}

console.log(criarMensagem());

Comentario de Documentacao

Comentarios de documentacao explicam o objetivo da funcao, seus parametros e retorno. Eles ajudam na leitura do codigo.

/**
 * Calcula o dobro de um numero.
 * @param {number} valor
 * @returns {number}
 */
function dobrar(valor) {
  return valor * 2;
}

Funcao Anonima

Uma funcao anonima nao tem nome proprio. Ela costuma ser guardada em uma variavel ou passada como argumento.

const mostrar = function () {
  console.log("Executando");
};

mostrar();

Arrow Function

Arrow function e uma sintaxe mais curta para criar funcoes. Ela e muito comum em JavaScript moderno.

const somar = (a, b) => {
  return a + b;
};

Quando a funcao tem apenas uma expressao, o retorno pode ficar implicito.

Callback Function

Callback e uma funcao passada para outra funcao. A funcao principal decide quando chamar esse comportamento.

function executarDepois(callback) {
  callback();
}

executarDepois(function () {
  console.log("Callback executado");
});
