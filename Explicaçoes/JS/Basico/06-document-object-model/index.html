DOM

DOM significa Document Object Model. Ele transforma o HTML em objetos que o JavaScript consegue acessar.

document.title;
document.body;

Inspecionando no Navegador

O navegador possui ferramentas de desenvolvedor. Na aba Elements voce observa o HTML real; na aba Console voce testa comandos JavaScript.

console.log(document.querySelector("h1"));

Acessando Elementos no DOM

Antes de alterar um elemento, voce precisa encontra-lo. Isso pode ser feito por id, classe, tag ou seletor CSS.

const titulo = document.getElementById("titulo");
const itens = document.getElementsByClassName("item");

Query Selector

querySelector busca o primeiro elemento que combina com um seletor CSS. querySelectorAll busca uma lista de elementos.

const botao = document.querySelector(".botao");
const cards = document.querySelectorAll(".card");

Manipulando Conteudo

Depois de selecionar um elemento, voce pode trocar o texto ou o HTML interno dele.

const titulo = document.querySelector("h1");
titulo.textContent = "Novo titulo";

Para texto simples, prefira textContent. Use innerHTML com cuidado.

Alterando Estilos

Voce pode alterar estilos diretamente, mas em projetos reais e comum adicionar ou remover classes CSS.

const caixa = document.querySelector(".caixa");
caixa.classList.add("ativo");
caixa.style.color = "yellow";

Criando Elementos

createElement cria um novo elemento. Depois, voce define conteudo e adiciona na pagina.

const item = document.createElement("li");
item.textContent = "Novo item";

document.querySelector("ul").append(item);

Manipulando Atributos

Atributos sao informacoes no HTML, como src, href, alt e disabled.

const link = document.querySelector("a");
link.setAttribute("href", "https://developer.mozilla.org");

console.log(link.getAttribute("href"));

Eventos

Eventos sao acontecimentos que o navegador avisa ao JavaScript, como clique, envio de formulario ou digitacao.

document.addEventListener("DOMContentLoaded", function () {
  console.log("Pagina pronta");
});

Eventos em um elemento especifico

Voce pode escutar eventos em um unico elemento, como um botao.

const botao = document.querySelector("button");

botao.addEventListener("click", function () {
  console.log("Clicou");
});

Eventos de formulario

O evento submit acontece quando um formulario e enviado. preventDefault impede o envio padrao quando voce precisa tratar os dados com JavaScript.

const form = document.querySelector("form");

form.addEventListener("submit", function (event) {
  event.preventDefault();
  console.log("Formulario capturado");
});

Eventos em input

O evento input acontece enquanto a pessoa digita, cola ou altera o valor do campo.

const campo = document.querySelector("input");

campo.addEventListener("input", function () {
  console.log(campo.value);
});

Compreendendo Expressao Regular

Expressao regular e um padrao usado para procurar, validar ou substituir partes de um texto.

const padraoEmail = /@/;

console.log(padraoEmail.test("ana@email.com")); // true

Utilizando o Regexr

Regexr e uma ferramenta visual para testar expressoes regulares. Use como laboratorio: escreva o padrao, cole textos de teste e observe o que foi encontrado.

/\\d+/ // encontra um ou mais digitos

Ele ajuda a estudar, mas sempre teste a expressao no JavaScript do seu projeto tambem.

Manipulando valor de input

O valor digitado em um campo fica em value. Voce pode ler esse valor, validar e ate alterar.

const input = document.querySelector("#nome");
const nome = input.value.trim();

input.value = nome.toUpperCase();
