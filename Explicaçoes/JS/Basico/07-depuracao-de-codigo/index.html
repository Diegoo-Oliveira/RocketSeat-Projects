O que e depurar o codigo?

Depurar e acompanhar o codigo como se voce estivesse vendo o passo a passo de uma receita. A ideia e descobrir qual linha cria o problema e quais valores existem naquele momento.

const preco = 20;
const quantidade = 3;
const total = preco * quantidade;

console.log(total);

O console e o primeiro aliado: ele mostra mensagens, erros e valores enquanto o programa roda.

Depurando o codigo

Uma forma pratica de depurar e usar console.log, ler a mensagem de erro e, quando precisar, pausar a execucao com debugger nas ferramentas do navegador.

function calcularTotal(preco, quantidade) {
  debugger;
  return preco * quantidade;
}

const total = calcularTotal(20, 3);
console.log(total);

Quando o navegador encontra debugger com as DevTools abertas, ele pausa a execucao. Assim voce consegue olhar variaveis, executar linha por linha e entender o caminho do codigo.

Depuracao nao e adivinhar. E observar: qual erro apareceu, em que linha, qual valor era esperado e qual valor apareceu.

Checklist rapido

  • Leia a mensagem de erro completa.
  • Veja o arquivo e a linha indicados pelo navegador.
  • Teste valores importantes com console.log.
  • Use debugger quando precisar ver a execucao passo a passo.
  • Corrija uma coisa por vez e teste novamente.
