Breakpoints

Breakpoints sao os "pontos de corte" onde o layout muda. Sao os valores de largura que voce usa no @media para decidir quando trocar o design. Nao existe um padrao obrigatorio, mas existem faixas que a maioria dos projetos usa.

Faixas mais comuns

A tabela abaixo mostra os breakpoints que a maioria dos frameworks e projetos profissionais utiliza.

Dispositivo Faixa Breakpoint
Celular pequeno 0 – 479px max-width: 479px
Celular grande 480 – 767px max-width: 767px
Tablet 768 – 1023px max-width: 1023px
Laptop 1024 – 1279px max-width: 1279px
Desktop 1280px + min-width: 1280px

Esses valores nao sao regras absolutas. O importante e testar no seu layout e ajustar onde ele "quebra".

Codigo com breakpoints

Usando max-width (desktop-first):

/* Padrao: layout para desktop */
.grid {
  display: grid;
  grid-template-columns: repeat(4, 1fr);
  gap: 20px;
}

/* Tablet: 3 colunas */
@media (max-width: 1023px) {
  .grid {
    grid-template-columns: repeat(3, 1fr);
  }
}

/* Celular grande: 2 colunas */
@media (max-width: 767px) {
  .grid {
    grid-template-columns: repeat(2, 1fr);
  }
}

/* Celular pequeno: 1 coluna */
@media (max-width: 479px) {
  .grid {
    grid-template-columns: 1fr;
  }
}

Regra de ouro

Nao defina breakpoints por dispositivo. Defina pelo conteudo: redimensione o navegador e observe onde o layout fica ruim. E ali que voce coloca o breakpoint.

  1. abra o layout no navegador
  2. va diminuindo a largura devagar
  3. quando algo "quebrar" ou ficar feio, anote a largura
  4. crie um @media nessa largura
  5. repita ate chegar na menor tela

Esse metodo garante que o layout funciona em qualquer tamanho, nao so nos dispositivos que voce testou.

Resumo

  1. breakpoints sao os valores de largura que disparam mudancas no layout
  2. celular, tablet, laptop e desktop sao faixas comuns, nao regras fixas
  3. o melhor breakpoint e onde o seu conteudo precisa mudar
  4. teste redimensionando o navegador, nao decorando numeros
