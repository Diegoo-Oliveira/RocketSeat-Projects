Media Features

Media features sao as condicoes que voce testa dentro do @media. A mais famosa e width, mas existem dezenas de outras para orientacao, resolucao, preferencia de cor, modo escuro e muito mais.

Dimensoes da viewport

As mais usadas no dia a dia. Todas aceitam prefixo min- e max-.

Feature O que testa Exemplo
width Largura exata da viewport (width: 1024px)
min-width Largura minima (a partir de) (min-width: 768px)
max-width Largura maxima (ate) (max-width: 767px)
height Altura exata da viewport (height: 900px)
min-height Altura minima (min-height: 600px)
max-height Altura maxima (max-height: 500px) 
/* Tela mais larga que 1024px */
@media (min-width: 1024px) {
  .container { max-width: 1200px; }
}

/* Tela com pouca altura (ex: landscape no celular) */
@media (max-height: 500px) {
  .hero { padding: 12px; }
}

Orientacao

Detecta se o dispositivo esta em pe (portrait) ou deitado (landscape).

Feature Quando e true
orientation: portrait Quando a altura e maior que a largura
orientation: landscape Quando a largura e maior que a altura 
/* Celular deitado: esconder sidebar, layout horizontal */
@media (orientation: landscape) and (max-height: 500px) {
  .sidebar { display: none; }
  .content { flex-direction: row; }
}

/* Celular em pe: layout vertical */
@media (orientation: portrait) {
  .gallery {
    grid-template-columns: 1fr;
  }
}

Combinar orientation com max-height e muito util para celulares deitados, onde a tela e larga mas baixa.

Proporcao da tela

Feature O que testa Exemplo
aspect-ratio Proporcao largura/altura (aspect-ratio: 16/9)
min-aspect-ratio Proporcao minima (min-aspect-ratio: 1/1)
max-aspect-ratio Proporcao maxima (max-aspect-ratio: 4/3) 
/* Telas ultra-wide (21:9 ou mais) */
@media (min-aspect-ratio: 21/9) {
  .hero {
    max-width: 1400px;
    margin: 0 auto;
  }
}

/* Telas quase quadradas */
@media (max-aspect-ratio: 4/3) {
  .video-container {
    aspect-ratio: 4/3;
  }
}

Resolucao e pixel density

Detecta telas de alta resolucao (Retina, HiDPI).

Feature O que testa
resolution Densidade em dpi ou dpcm
min-resolution Densidade minima
-webkit-device-pixel-ratio Compatibilidade com Safari antigo 
/* Telas Retina (2x ou mais) */
@media (min-resolution: 2dppx) {
  .logo {
    background-image: url('logo@2x.png');
    background-size: 200px 60px;
  }
}

/* Alternativa com -webkit para Safari */
@media (-webkit-min-device-pixel-ratio: 2) {
  .logo {
    background-image: url('logo@2x.png');
  }
}

dppx = dots per pixel. 2dppx = tela Retina (2 pixels fisicos para cada pixel CSS).

Preferencias do usuario

Features modernas que respeitam as configuracoes do sistema operacional do usuario.

Feature O que detecta
prefers-color-scheme Modo claro ou escuro do sistema
prefers-reduced-motion Usuario pediu menos animacoes
prefers-contrast Usuario quer mais ou menos contraste
prefers-reduced-transparency Usuario quer menos transparencia 
/* Modo escuro automatico */
@media (prefers-color-scheme: dark) {
  :root {
    --bg: #0f172a;
    --panel: #1e293b;
    --ink: #e2e8f0;
    --muted: #94a3b8;
  }
}

/* Desativar animacoes para usuarios sensiveis */
@media (prefers-reduced-motion: reduce) {
  * {
    animation-duration: 0.01ms !important;
    transition-duration: 0.01ms !important;
  }
}

/* Alto contraste */
@media (prefers-contrast: more) {
  :root {
    --ink: #000000;
    --bg: #ffffff;
    --line: #000000;
  }
}

prefers-color-scheme e prefers-reduced-motion sao as mais importantes. Sempre que possivel, implemente as duas nos seus projetos.

Capacidades do dispositivo

Feature O que detecta
hover: hover Dispositivo tem cursor que "hovera"
hover: none Toque, sem hover (celular)
pointer: fine Ponteiro preciso (mouse)
pointer: coarse Ponteiro impreciso (dedo)
any-hover Qualquer input disponivel
any-pointer Qualquer tipo de ponteiro 
/* Efeito hover so em dispositivos com mouse */
@media (hover: hover) {
  .card:hover {
    transform: translateY(-4px);
    box-shadow: 0 12px 24px rgba(0,0,0,0.15);
  }
}

/* Botoes maiores em dispositivos touch */
@media (pointer: coarse) {
  .button {
    min-height: 48px;
    padding: 14px 20px;
    font-size: 1rem;
  }
}

/* Botoes normais em dispositivos com mouse */
@media (pointer: fine) {
  .button {
    min-height: 36px;
    padding: 8px 14px;
  }
}

Usar hover: hover evita que efeitos hover "grudem" em celulares. Em touch, o hover fica ativo apos o toque e causa confusao visual.

Resumo das features

  1. width/height: as mais usadas, com prefixos min- e max-
  2. orientation: portrait (em pe) vs landscape (deitado)
  3. aspect-ratio: proporcao da tela
  4. resolution: telas Retina e HiDPI
  5. prefers-color-scheme: modo escuro automatico
  6. prefers-reduced-motion: acessibilidade
  7. hover/pointer: mouse vs toque
