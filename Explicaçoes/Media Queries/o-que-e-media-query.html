O que e @media

@media e uma regra CSS que aplica estilos somente quando uma condicao e verdadeira. Pense como um if do CSS: "se a tela for menor que 768px, faca isso". Ela e a base de tudo que chamamos de responsividade.

Anatomia da regra

Toda media query segue o mesmo padrao: a palavra @media, uma condicao entre parenteses e um bloco de CSS que so vale quando a condicao for verdadeira. 

@media (condicao) {
  /* CSS que so vale quando a condicao e verdadeira */
  .elemento {
    propriedade: valor;
  }
}

As chaves externas abrem e fecham o bloco do @media. Dentro dele voce escreve CSS normal, como se fosse outra folha de estilos.

Exemplo basico

Mudar a cor de fundo do body quando a tela for menor que 768px. 

/* Estilo padrao (para telas grandes) */
body {
  background: #ffffff;
  color: #172033;
}

/* Quando a tela for ate 768px */
@media (max-width: 768px) {
  body {
    background: #0f172a;
    color: #e2e8f0;
  }
}

O navegador le o CSS de cima para baixo. Se a tela tiver 600px, primeiro aplica background branco, depois entra no @media e sobrescreve para o fundo escuro.

Como o navegador avalia

  1. O navegador carrega todo o CSS normalmente
  2. Ao encontrar @media, verifica a condicao
  3. Se a condicao for verdadeira, aplica o bloco
  4. Se for falsa, ignora completamente o bloco
  5. Ao redimensionar a janela, reavalia em tempo real

E por isso que voce ve o layout mudar ao arrastar a borda do navegador: o @media e checado continuamente.

Onde escrever

Voce pode usar @media em tres lugares:

/* 1. Dentro do proprio arquivo CSS */
@media (max-width: 768px) { ... }

/* 2. Na tag link do HTML (carrega o arquivo
      somente quando a condicao bate) */
<link rel="stylesheet"
      href="mobile.css"
      media="(max-width: 768px)">

/* 3. Dentro de uma tag style no HTML */
<style>
  @media (max-width: 768px) { ... }
</style>

O jeito mais comum e escrever tudo no final do mesmo arquivo CSS. Assim voce mantem tudo em um lugar so, facil de ler e manter.

Resumo rapido

  1. @media e um "if" do CSS que testa condicoes da tela
  2. so aplica os estilos quando a condicao e verdadeira
  3. e reavaliado em tempo real ao redimensionar a janela
  4. pode ser escrito no CSS, no HTML com link ou com style
