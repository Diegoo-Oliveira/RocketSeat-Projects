Como trocar a cor de icones SVG

No Portfolio Dev, os icones aparecem brancos porque os arquivos SVG trazem a cor fixa dentro deles. Para mudar isso, voce precisa escolher entre uma solucao simples, com cor fixa no arquivo, ou uma solucao um pouco mais flexivel, onde o SVG obedece uma cor definida no CSS.

O motivo

Por que o CSS do pai nao muda um SVG usado com img?

Quando voce escreve um icone assim, o navegador trata o SVG como uma imagem externa: 

<img src="Assets/icons/HTML.svg" alt="">

Dentro do arquivo SVG existe algo parecido com isto: 

<path d="..." fill="#E2E4E9" />

Esse fill e a cor do desenho. Como ele esta dentro de outro arquivo e esta fixo como #E2E4E9, uma classe no pai nao consegue alterar essa cor diretamente.

Mais simples

Opcao 1: mudar a cor direto no arquivo SVG

Esta e a forma mais facil para o momento atual dos seus estudos. Abra o SVG e troque o valor do fill pela cor desejada. 

/* Antes */
fill="#E2E4E9"

/* Depois, exemplo do HTML no Portfolio Dev */
fill="#E3646E"

No seu projeto, voce poderia usar as mesmas cores que ja existem no :root:

HTML: #E3646E CSS/React/setas: #3996DB JavaScript/API: #EABD5F Node/DevOps: #82BC4F Websites e aplicativos: #BB72E9

Cuidado: se o mesmo arquivo SVG for usado em dois lugares, mudar a cor dele muda em todos os lugares. Se precisar de duas cores, crie uma copia com outro nome, por exemplo GitHub-gray.svg e GitHub-blue.svg.

Mais flexivel

Opcao 2: usar SVG inline com currentColor

Se voce quer que o icone obedeca uma cor definida pelo CSS, o SVG precisa estar dentro do HTML, nao chamado por img. Nesse caso, troque a cor fixa por currentColor. 

<div class="tag html">
  <svg width="32" height="32" viewBox="0 0 32 32">
    <path d="..." fill="currentColor" />
  </svg>
  <span>HTML</span>
</div>
.tag {
  --icon-color: var(--gray-300);
}

.tag.html {
  --icon-color: var(--red);
}

.tag svg {
  width: 24px;
  height: 24px;
  color: var(--icon-color);
}

A palavra currentColor significa: use o valor da propriedade color. Por isso o CSS consegue controlar o icone sem alterar o desenho do SVG.

Portfolio Dev

Como deixar parecido com o Figma sem complicar

Para o seu projeto atual, o caminho mais simples e este:

  1. Para icones que sempre terao a mesma cor, altere o fill direto no SVG.
  2. Para icones repetidos em lugares diferentes, crie uma copia do SVG com outro nome.
  3. Para um icone obedecer a cor de uma classe pai, use SVG inline com currentColor.
  4. Se o SVG tiver stroke em vez de fill, troque o valor do stroke, nao do fill. 
.service-card.web {
  --icon-color: var(--purple);
}

.service-card.api {
  --icon-color: var(--yellow);
}

.service-card.devops {
  --icon-color: var(--green);
}

.service-card svg {
  color: var(--icon-color);
}

Evite tentar resolver isso com filter no CSS. Funciona em alguns casos, mas os valores ficam estranhos e dificilmente batem exatamente com o Figma.

Hover

Como fazer o hover do SocialButton do Figma

O hover do Figma tem tres coisas acontecendo ao mesmo tempo: a borda fica azul, o icone da esquerda fica azul e a seta da direita tambem fica azul. A parte facil e a borda: 

.social-button {
  border: 1px solid transparent;
}

.social-button:hover {
  border-color: var(--blue);
}

A parte dificil e trocar a cor dos icones. Se eles continuarem como img, voce tem duas saidas simples:

  1. Criar uma versao azul do SVG e trocar a imagem no hover.
  2. Usar SVG inline com currentColor e mudar a cor no hover.

A opcao com duas imagens e mais simples para o que voce ja estudou: 

<a class="social-button" href="#">
  <img class="icon-default" src="Assets/icons/LinkedinLogo.svg" alt="">
  <img class="icon-hover" src="Assets/icons/LinkedinLogo-blue.svg" alt="">
  <span class="text-md">LinkedIn</span>
  <img class="arrow" src="Assets/icons/ArrowUpRight-blue.svg" alt="">
</a>
.icon-hover {
  display: none;
}

.social-button:hover .icon-default {
  display: none;
}

.social-button:hover .icon-hover {
  display: block;
}

Essa solucao repete um pouco o HTML, mas e facil de entender: no estado normal aparece um icone; no hover aparece outro. Depois, quando voce estiver confortavel com SVG inline, da para refatorar para currentColor.
