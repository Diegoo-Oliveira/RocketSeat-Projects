Tutorial de projeto

Como montar o Formulário de Matrícula a partir do Figma

Este projeto ensina uma parte muito importante do front-end: criar uma página de formulário grande sem perder organização. O segredo é ler o layout por blocos, montar o HTML semântico primeiro e só depois cuidar dos detalhes visuais.

Leitura do layout

Antes do código, entenda a tela como duas colunas

Pelo node `3:809` do Figma, a tela principal tem um frame chamado "Forms de matrícula escola", com `1280px` de largura e `848px` de altura. Dentro dele existem duas áreas: o formulário à esquerda e uma área visual/institucional à direita.

Essa leitura já decide quase todo o CSS: o pai usa Grid com duas colunas, a coluna esquerda concentra o `form`, e a coluna direita funciona como um painel fixo com marca, texto e ilustração.

Form area 656px
Painel visual 624px
Mapa do Figma

O formulário é grande, mas ele se repete em blocos simples

A coluna esquerda tem `64px` de respiro lateral e um conteúdo central com `528px`. A partir daí, o Figma organiza o formulário em grupos: cabeçalho, dados da criança, endereço, responsável, opções de matrícula, aceite dos termos e ações finais.

1. Cabeçalho

Link de voltar, título "Formulário de matrícula" e texto introdutório.

2. Informações da criança

Nome, nascimento, sexo, informações médicas e envio da certidão.

3. Endereço residencial

CEP, rua, número, cidade e estado, com campos lado a lado.

4. Responsável

Nome do responsável, telefone e e-mail para contato.

5. Opções de matrícula

Cards de turno e cards de esportes selecionáveis.

6. Finalização

Checkbox de termos e botões "Salvar respostas" e "Fazer matrícula".

Style Guide

Use o Style Guide como fonte oficial antes de criar seus próprios estilos

O node `2190:1725` do Figma é o apoio mais importante para esse projeto. Ele deve ser consultado antes de escrever o CSS final, porque ali ficam os padrões que se repetem: cores, textos, inputs, botões, checkbox e cards de seleção.

A ordem boa de estudo é esta: primeiro leia o layout completo para entender a página; depois abra o Style Guide para copiar os padrões reutilizáveis; por fim, volte ao layout e aplique esses padrões nas seções reais.

Cores

Mapeie fundo, texto, borda, destaque, hover, erro e selecionado.

Tipografia

Confira família, peso, tamanho e line-height de títulos, labels e textos.

FormControl

Use como base para input, select, textarea, foco, erro e estado preenchido.

SelectionCard

Reaproveite nos turnos e esportes, mudando apenas ícone e texto.

Button

Identifique o botão primário, o secundário e seus estados de interação.

Checkbox

Use para o aceite dos termos e para entender tamanho e alinhamento.

Estrutura

Crie uma pasta focada em formulário, não em página genérica

Como este projeto tem muitos tipos de campo, vale separar CSS base, componentes de formulário e layout. Isso ajuda a não misturar regra de coluna com regra de input. 

Projetos/Formulario-Matricula/
  index.html
  assets/
    icons/
    images/
  styles/
    global.css
    form.css
    layout.css
    buttons.css
    index.css
Passo 1

Monte o HTML com `form`, `fieldset` e `label`

Em formulário, semântica importa bastante. Cada grupo do Figma pode virar um `fieldset`, cada título de grupo vira `legend`, e todo campo deve ter um `label` conectado pelo `for`. 

<main class="enrollment-page">
  <section class="form-area">
    <a class="back-link" href="#">Voltar</a>

    <header class="form-header">
      <h1>Formulário de matrícula</h1>
      <p>Preencha os dados abaixo para matricular seu filho...</p>
    </header>

    <form>
      <fieldset>
        <legend>Informações da criança</legend>
      </fieldset>
    </form>
  </section>

  <aside class="brand-panel">...</aside>
</main>
Passo 2

Transforme o Figma em tokens no `:root`

Não comece espalhando cores direto nos campos. Primeiro crie variáveis com nomes de função: superfície, texto, borda, destaque, erro e largura. Depois você ajusta os valores exatos olhando o Style Guide e o Inspect do Figma. 

:root {
  --surface-primary: #ffffff;
  --surface-secondary: #fee7d6;
  --text-primary: #292524;
  --text-secondary: #57534e;
  --text-tertiary: #8f8881;
  --stroke-default: #d6d3d1;
  --stroke-highlight: #f3541c;
  --semantic-error: #dc2626;

  --form-width: 528px;
  --page-gap: 64px;
  --radius-md: 8px;
}
Passos 3 a 8

Construa o projeto por camadas

3

Crie o layout principal com Grid

O frame do Figma tem duas colunas: `656px` para o formulário e `624px` para o painel lateral. No navegador, use `minmax` para permitir adaptação. 

.enrollment-page {
  min-height: 100vh;
  display: grid;
  grid-template-columns: minmax(0, 656px) minmax(420px, 1fr);
}

.form-area {
  padding: 64px;
}
4

Padronize os campos em um componente

O Figma usa várias instâncias de `FormControl`. No HTML/CSS, isso vira uma classe base reutilizável para label, input, select e textarea. 

.field {
  display: grid;
  gap: 4px;
}

.field label {
  color: var(--text-secondary);
  font-size: 0.875rem;
}

.field input,
.field select,
.field textarea {
  width: 100%;
  border: 1px solid var(--stroke-default);
  border-radius: var(--radius-md);
  padding: 12px 16px;
}
5

Use grids pequenos dentro dos fieldsets

No endereço, o Figma coloca alguns campos lado a lado. Em vez de criar várias larguras soltas, crie uma linha reutilizável. 

.fieldset {
  display: grid;
  gap: 24px;
  border: 0;
  padding: 0;
}

.fields-row {
  display: grid;
  grid-template-columns: 2fr 1fr;
  gap: 20px;
}
6

Monte o upload como um campo especial

A certidão de nascimento não deve parecer um input comum. Crie uma área com borda tracejada, ícone e texto. O input real pode ficar invisível, mas ainda acessível pelo `label`. 

<label class="upload-field" for="birth-file">
  <input id="birth-file" type="file" />
  <span>Clique aqui para selecionar o arquivo</span>
</label>
7

Faça cards selecionáveis com radio e checkbox

Para manter simples, deixe o `input` antes do `label`. Assim você consegue estilizar o card selecionado com `input:checked + label`, sem precisar de JavaScript. 

<input class="sr-only" type="radio" id="morning" name="shift" />
<label class="choice-card" for="morning">Manhã</label>

.sr-only:checked + .choice-card {
  border-color: var(--stroke-highlight);
  background: #fff7f2;
}
8

Finalize com botões e estados visuais

O formulário termina com dois botões. O secundário pode ser claro com borda, e o primário pode usar a cor de destaque do layout. 

.form-actions {
  display: flex;
  justify-content: flex-end;
  gap: 16px;
}

.button.primary {
  border-color: var(--stroke-highlight);
  background: var(--stroke-highlight);
  color: #ffffff;
}
Responsivo

No mobile, o painel lateral deixa de ser prioridade

O Figma mostra a versão desktop. Para telas menores, a melhor decisão é empilhar as áreas ou esconder a ilustração, mantendo o formulário confortável para preenchimento. 

@media (max-width: 960px) {
  .enrollment-page {
    grid-template-columns: 1fr;
  }

  .brand-panel {
    order: -1;
    padding: 32px;
  }
}

@media (max-width: 640px) {
  .form-area {
    padding: 24px;
  }

  .fields-row,
  .options-grid {
    grid-template-columns: 1fr;
  }
}
Checklist final

Como saber se o projeto ficou bem estruturado

  1. O layout principal usa duas colunas no desktop?
  2. O formulário está dentro de uma tag `form` real?
  3. Os grupos usam `fieldset` e `legend`?
  4. Todo campo tem `label` conectado ao input?
  5. Os campos repetidos usam a mesma classe base?
  6. Os cards de turno e esporte funcionam sem JavaScript?
  7. O mobile empilha campos antes de eles ficarem apertados?
  8. As cores, larguras e espaçamentos importantes estão em variáveis?
