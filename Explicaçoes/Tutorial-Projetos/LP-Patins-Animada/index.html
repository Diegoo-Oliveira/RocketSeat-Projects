Tutorial mobile-first + animacoes

Como reconstruir a LP de Patins Animada

Este roteiro explica como montar a landing page da Snitap do zero: estrutura de pastas, HTML semantico, CSS modular separado por secao, abordagem mobile-first com @media (min-width) e as animacoes com @keyframes, transition e animation-timeline: view(). Cada passo mostra o HTML e o CSS juntos, com explicacao do que cada propriedade faz.

Passo 0

Estrutura de pastas e arquivos

O projeto organiza o CSS em varios arquivos separados por secao. O styles/index.css e o centralizador: ele importa todos os outros na ordem certa. 

lp-de-patins-animada/
├── index.html
├── assets/
│   ├── logo.svg
│   ├── banner.svg
│   ├── icons/
│   │   ├── shopping-bag.svg
│   │   └── play.svg
│   ├── hero/
│   │   ├── patins-image.png
│   │   ├── ellipse.svg
│   │   ├── stars-1.svg
│   │   └── stars-2.svg
│   └── gallery/
│       ├── image-1.png  image-2.png
│       ├── image-3.png  image-4.png
└── styles/
    ├── index.css      ← importa todos os outros
    ├── global.css     ← reset e variaveis CSS
    ├── header.css     ← cabecalho
    ├── hero.css       ← secao principal
    ├── banner.css     ← faixa rolante
    ├── gallery.css    ← galeria de fotos
    └── footer.css     ← rodape

O styles/index.css fica assim:

/* styles/index.css */
@import url(global.css);
@import url(header.css);
@import url(hero.css);
@import url(banner.css);
@import url(gallery.css);
@import url(footer.css);

Por que separar? Facilita a manutencao. Em vez de procurar o estilo do header num arquivo de 500 linhas, voce vai direto em header.css. E uma boa pratica profissional.

Passo 1 – global.css

Reset universal e variaveis CSS (Design Tokens)

Antes de qualquer componente, definimos o reset e as variaveis que serao usadas em todo o projeto. Mudar uma cor aqui muda em todo o site.

1

Reset universal

Remove margens, paddings e garante que o box-sizing funcione corretamente em todos os elementos, incluindo pseudo-elementos.

*,
*::after,
*::before {
  margin: 0;
  padding: 0;
  box-sizing: border-box;
}

box-sizing: border-box faz o padding e border ficarem dentro da largura total do elemento. Sem isso, um elemento com width: 200px e padding: 20px ocuparia 240px na tela.

2

Variaveis CSS – paleta de cores

Todas as cores do projeto definidas em :root, disponíveis em qualquer arquivo CSS.

:root {
  /* Cores da marca */
  --snitap-sun:       #ffcd1e;  /* amarelo – botao comprar */
  --snitap-sky-mid:   #06b6d4;  /* ciano   – palavra "radical" */
  --snitap-sky-light: #67e8f9;  /* ciano claro – banner */
  --snitap-joy-mid:   #db2777;  /* rosa    – palavra "divertida" */
  --snitap-joy-light: #f472b6;  /* rosa claro – banner */
  --snitap-leaf-mid:  #16a34a;  /* verde   – palavra "saudavel" */

  /* Cores de interface */
  --text:       #000000;
  --highlights: #000000;
  --background: #fafafa;

  /* Fontes */
  --ff-base:   'Montserrat', sans-serif;
  --ff-accent: 'Syne', sans-serif;

  /* Escala tipografica */
  --text-sm:  0.875rem;  /* 14px */
  --text-md:  1rem;      /* 16px */
  --text-lg:  1.25rem;   /* 20px */
  --text-xl:  1.5rem;    /* 24px */
  --text-2xl: 2rem;      /* 32px */
  --text-3xl: 3rem;      /* 48px */
  --text-4xl: 5rem;      /* 80px */
}

Por que rem e nao px? rem e relativo ao tamanho base do browser (geralmente 16px). Se o usuario aumentar a fonte nas configuracoes de acessibilidade, o site inteiro se ajusta. px e fixo e ignora isso.

3

Estilos base do body, links e imagens

body {
  font-family: var(--ff-base);
  background-color: var(--background);
  color: var(--text);
}

a {
  text-decoration: none;  /* remove sublinhado padrao */
  color: inherit;         /* herda cor do pai */
}

img {
  display: block;  /* remove espaco extra abaixo de imagens inline */
}
4

Google Fonts no index.html

Adicionar as fontes antes do </head>. O projeto usa 3 fontes: Montserrat, Inter e Syne.

<link rel="preconnect" href="https://fonts.googleapis.com" />
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin />
<link
  href="https://fonts.googleapis.com/css2?family=Inter:wght@500
        &family=Montserrat:ital,wght@0,500;1,500
        &family=Syne:wght@700&display=swap"
  rel="stylesheet"
/>

rel="preconnect" instrui o browser a abrir a conexao com o servidor de fontes antes mesmo de precisar. Isso acelera o carregamento.

Passo 2 – Header

Cabecalho: logo + carrinho com hover animado

O header usa Flexbox para separar logo e carrinho. As imagens giram ao passar o mouse usando transform e transition. O badge do carrinho e posicionado com position: absolute.

1

HTML do header

<header class="top">
  <a href="#">
    <img src="assets/logo.svg" alt="" />
  </a>

  <a href="#">
    <img src="assets/icons/shopping-bag.svg" alt="" />
    <span>1</span>
  </a>
</header>

Por que alt="" vazio? Imagens decorativas (logo e icone) devem ter alt="" para que leitores de tela as ignorem. Reservamos o alt descritivo para imagens com conteudo.

2

CSS – layout e hover das imagens

/* header.css */
header.top {
  max-width: 80rem;
  width: 100%;
  padding: 1.25rem 2rem;
  margin-inline: auto;   /* centraliza horizontalmente */

  display: flex;
  align-items: center;
  justify-content: space-between;  /* logo na esq, carrinho na dir */

  img {
    width: 2rem;
    height: 2rem;
    transition: transform 500ms;   /* suaviza a rotacao */
  }

  img[src*='logo']:hover {
    transform: rotate(90deg);      /* logo gira ao hover */
  }

  img[src*='shopping']:hover {
    transform: rotate(-30deg);     /* sacola balanca ao hover */
  }
}

Seletor de atributo [src*='logo'] seleciona imagens onde o src contém a string 'logo'. Assim aplicamos comportamentos diferentes sem precisar de classes extras no HTML.

3

CSS – badge circular do carrinho

/* Ainda em header.css */
header.top a:last-child {
  position: relative;   /* contexto para o span absolute */
  display: flex;
  align-items: center;

  span {
    position: absolute;
    top: -0.5rem;
    right: -0.75rem;

    width: 1.25rem;
    height: 1.25rem;
    display: flex;
    align-items: center;
    justify-content: center;

    background-color: var(--snitap-joy-mid);
    color: white;
    border-radius: 50%;   /* circulo perfeito */

    font: 500 0.625rem/1 'Inter', sans-serif;
  }
}

position: relative no pai + absolute no filho e o padrao de posicionamento. Sem o relative no <a>, o badge se posicionaria em relacao ao body e sairia de lugar.

Passo 3 – Hero Section

Secao principal: texto rotativo, patins flutuando e estrelas girando

A hero e a secao mais complexa. Ela tem tres animacoes: as palavras deslizando verticalmente com @keyframes slideUp, os patins flutuando com @keyframes float e as estrelas girando com @keyframes spin.

1

HTML completo da hero

<section class="hero">
  <!-- Lado esquerdo: texto e botoes -->
  <div>
    <h1>
      Snitap, sua vida mais
      <div>
        <!-- 4 spans: o 4o repete o 1o para o loop ficar suave -->
        <span>radical</span>
        <span>divertida</span>
        <span>saudavel</span>
        <span>radical</span>
      </div>
    </h1>

    <div class="buttons">
      <a href="#" class="button buy">
        <img src="assets/icons/shopping-bag.svg" alt="" />
        Comprar agora
      </a>
      <a href="#" class="button play">
        <div class="play-icon">
          <img src="assets/icons/play.svg" alt="" />
        </div>
        Ver demonstracao
      </a>
    </div>
  </div>

  <!-- Lado direito: imagem e decoracoes -->
  <div class="image-wrapper">
    <img class="ellipse" src="assets/hero/ellipse.svg" alt="" />
    <img class="patins" src="assets/hero/patins-image.png"
         alt="Patins colorido" />
    <img class="stars stars-1" src="assets/hero/stars-1.svg" alt="" />
    <img class="stars stars-2" src="assets/hero/stars-2.svg" alt="" />
  </div>
</section>

Por que o 4o span repete "radical"? Para o loop ser imperceptivel. Quando chegamos ao fim, voltamos ao inicio — mas como o ultimo e identico ao primeiro, o salto acontece fora da area visivel.

2

CSS – animacao de texto: a "janela" com overflow hidden

O truque: o <div> que envolve os spans tem altura fixa e overflow: hidden, funcionando como uma janela que mostra apenas uma palavra por vez.

section.hero {
  max-width: 80rem;
  width: 100%;
  padding: 2.5rem 2rem;
  margin-inline: auto;
  display: flex;
  align-items: center;
  justify-content: space-between;
  overflow: hidden;

  /* Container das palavras rotativas */
  & h1 div {
    display: inline-block;
    overflow: hidden;        /* ← esconde palavras fora da area */
    height: 5rem;            /* ← mostra apenas 1 palavra por vez */
    width: min-content;
    vertical-align: bottom;  /* alinha com o texto ao lado */
  }

  /* Cores de cada palavra */
  & h1 span:nth-child(1),
  & h1 span:nth-child(4) { color: var(--snitap-sky-mid); }
  & h1 span:nth-child(2) { color: var(--snitap-joy-mid); }
  & h1 span:nth-child(3) { color: var(--snitap-leaf-mid); }

  /* Cada span e um bloco e anima para cima */
  & h1 span {
    display: block;
    animation: slideUp 5s 2s infinite ease;
  }
}
3

@keyframes slideUp – como funciona a troca de palavras

A animacao move o bloco inteiro para cima em etapas. Como o container so mostra 5rem de altura, parece que as palavras trocam.

@keyframes slideUp {
  /* Fica parado em cada posicao por um tempo */
  0%,  20% { transform: translateY(0);     }  /* "radical"   visivel */
  25%, 45% { transform: translateY(-100%); }  /* "divertida" visivel */
  50%, 70% { transform: translateY(-200%); }  /* "saudavel"  visivel */
  75%,100% { transform: translateY(-300%); }  /* "radical"   (copia) */
}

/* animation: nome duracao delay repeticao timing-function */
animation: slideUp 5s 2s infinite ease;

Por que usar translateY e nao top? transform nao causa reflow — o browser so move o elemento na GPU, sem recalcular o layout inteiro. Muito mais performatico.

4

CSS – botoes com scale no hover

& .buttons {
  display: flex;
  gap: 2rem;
  margin-top: 3rem;

  & .button {
    display: flex;
    align-items: center;
    gap: 0.75rem;
    border-radius: 5rem;
    transition: scale 350ms;   /* suaviza o crescimento */

    &.buy {
      padding: 1.5rem 3rem;
      background-color: var(--snitap-sun);
    }

    &.play .play-icon {
      width: 3.5rem;
      height: 3.5rem;
      display: flex;
      align-items: center;
      justify-content: center;
      background-color: var(--highlights);
      border-radius: 50%;

      img { filter: invert(1); }  /* torna o icone branco */
    }

    &:hover { scale: 1.05; }  /* cresce 5% ao passar o mouse */
  }
}

filter: invert(1) inverte as cores da imagem. O icone de play e preto, mas o fundo e preto — entao invertemos para branco sem precisar de uma segunda versao do SVG.

5

CSS – patins flutuando e estrelas girando

& .image-wrapper {
  position: relative;
  flex-shrink: 0;

  & .ellipse { width: 28rem; }

  & .patins {
    width: 36rem;
    position: absolute;
    top: 50%;
    left: 50%;
    transform: translate(-50%, -55%);  /* centralizacao absoluta */
    animation: float 3s ease-in-out infinite;
  }

  & .stars {
    position: absolute;
    animation: spin 6s linear infinite;
  }

  & .stars-1 { top: 10%; right: 5%; width: 3rem; }
  & .stars-2 {
    bottom: 15%; left: 5%; width: 2rem;
    animation-direction: reverse;  /* gira ao contrario */
  }
}

@keyframes float {
  0%, 100% { transform: translate(-50%, -55%); }
  50%       { transform: translate(-50%, -60%); }
}

@keyframes spin {
  from { rotate: 0deg; }
  to   { rotate: 360deg; }
}

translate(-50%, -50%) e o truque classico de centralizacao absoluta: top: 50%; left: 50% move o canto superior esquerdo para o centro. O translate(-50%) volta metade do proprio tamanho, centralizando de verdade.

Passo 4 – Banner Rolante

Faixa de texto com rolagem infinita e gradiente animado

1

HTML – duplicar imagens para o loop

<section class="banner bg-gradient-animate">
  <div class="scroller">
    <div class="rolling">
      <!-- Mesma imagem 4 vezes para o loop ser imperceptivel -->
      <img src="assets/banner.svg" alt="snitap patins" />
      <img src="assets/banner.svg" alt="snitap patins" />
      <img src="assets/banner.svg" alt="snitap patins" />
      <img src="assets/banner.svg" alt="snitap patins" />
    </div>
  </div>
</section>
2

CSS – rolagem com translateX(-50%)

.banner {
  width: 100%;
  padding-block: 2.5rem;
  overflow: hidden;   /* esconde o que sai da tela */

  .scroller {
    overflow: hidden;
    padding-block: 1rem;
  }

  .rolling {
    display: flex;
    gap: 1.5rem;
    animation: rolling 20s linear infinite;
  }
}

@keyframes rolling {
  from { transform: translateX(0); }
  to   { transform: translateX(-50%); }  /* move metade do total */
}

Por que -50%? Temos 4 copias da imagem. A animacao move exatamente metade (2 imagens). Quando reinicia, a posicao visual e identica ao inicio — o loop e imperceptivel.

linear e essencial aqui! Diferente de ease, mantem velocidade constante — necessario para o efeito de esteira.

3

CSS – gradiente animado no fundo

.bg-gradient-animate {
  background: linear-gradient(
    90deg,
    var(--snitap-sky-light),
    var(--snitap-joy-light),
    var(--snitap-sun),
    var(--snitap-sky-light)  /* repete a primeira cor para loop */
  );
  background-size: 300% 100%;  /* gradiente 3x maior */
  animation: gradient-move 4s ease infinite;
}

@keyframes gradient-move {
  0%   { background-position: 0% 50%; }
  50%  { background-position: 100% 50%; }
  100% { background-position: 0% 50%; }
}

O gradiente e criado 3x maior que o elemento com background-size: 300%. A animacao "desliza" esse gradiente gigante com background-position, criando o efeito de cores fluindo.

Passo 5 – Galeria de Fotos

CSS Grid com areas nomeadas e animacao por scroll

A galeria usa grid-template-areas para criar um layout assimetrico, e animation-timeline: view() para animar as imagens conforme o usuario rola a pagina.

1

HTML da galeria

<section class="gallery">
  <header>
    <span>Nossa galeria</span>
    <h2>Momentos que valem a pena</h2>
  </header>

  <div class="content">
    <figure>
      <img src="assets/gallery/image-1.png"
           alt="Pessoa andando de patins" />
    </figure>

    <figure data-delay>
      <img src="assets/gallery/image-2.png"
           alt="Patins coloridos" />
    </figure>

    <figure data-delay>
      <img src="assets/gallery/image-3.png"
           alt="Grupo andando de patins" />
    </figure>

    <figure>
      <img src="assets/gallery/image-4.png"
           alt="Patins em close" />
    </figure>
  </div>
</section>

data-delay e um atributo de dados HTML usado como seletor CSS para dar um delay diferente na animacao de entrada de algumas imagens, criando um efeito escalonado.

2

CSS – Grid com areas nomeadas

section.gallery .content {
  margin-top: 2rem;
  display: grid;
  grid-template-areas:
    'A B B'   /* B ocupa 2 colunas */
    'C C D';  /* C ocupa 2 colunas */
  gap: 2.5rem;
}

/* Atribuindo cada figure a uma area */
figure:nth-child(1) { grid-area: A; }
figure:nth-child(2) { grid-area: B; }
figure:nth-child(3) { grid-area: C; }
figure:nth-child(4) { grid-area: D; }

Resultado visual do grid:

┌───┬───────┐
│ A │   B   │  ← B: retangulo largo (2 cols)
├───────┬───┤
│   C   │ D │  ← C: retangulo largo (2 cols)
└───────┴───┘
3

CSS – animation-timeline: view() (animacao por scroll)

figure {
  border-radius: 2.5rem;
  overflow: hidden;    /* para o hover de zoom nao vazar */
  line-height: 0;      /* remove espaco extra abaixo da imagem */

  /* Animacao de entrada ao rolar */
  animation: image-appear linear backwards;
  animation-timeline: view();      /* controlada pelo scroll! */
  animation-range: 100px 300px;    /* quando comecar e terminar */

  &[data-delay] {
    animation-range: 150px 350px;  /* delay: comeca mais tarde */
  }

  /* Zoom da imagem ao hover */
  &:hover img { scale: 1.05; }
  img { transition: scale 500ms; }
}

@keyframes image-appear {
  from { opacity: 0; scale: 0.8; }
  to   { opacity: 1; scale: 1; }
}

Compatibilidade: animation-timeline: view() funciona no Chrome 115+ e Edge 115+. Firefox e Safari tem suporte limitado. Use como melhoria progressiva — em browsers sem suporte, as imagens aparecem normalmente sem animacao.

CSS – underline animado com ::after

O efeito de sublinhado que cresce ao hover e feito com ::after — um pseudo-elemento virtual criado so pelo CSS. 

footer nav a {
  width: fit-content;
  position: relative;   /* contexto para o ::after */

  /* Linha invisivel abaixo do texto */
  &::after {
    content: '';           /* pseudo-elemento precisa de content */
    position: absolute;
    bottom: -2px;
    left: 0;

    width: 100%;
    height: 1px;
    background-color: currentColor; /* mesma cor do texto */

    opacity: 0;
    transform: scaleX(0);          /* largura zero */
    transform-origin: left;        /* cresce da esquerda */

    transition: opacity 300ms, transform 300ms;
  }

  /* Ao hover: linha aparece crescendo da esquerda */
  &:hover::after {
    opacity: 1;
    transform: scaleX(1);  /* largura total */
  }
}

Por que scaleX e nao width? Animar width causa reflow — o browser recalcula o layout inteiro. Animar transform: scaleX roda na GPU sem tocar no layout. Muito mais fluido.

currentColor usa a cor herdada do texto. Se o link mudar de cor, o sublinhado acompanha automaticamente.

Passo 7 – Mobile First

Adaptando cada secao: do celular para o desktop

O padrao e sempre o mesmo: CSS base e para celular (simples, empilhado). Os @media (min-width) adicionam complexidade progressivamente. Nunca desfazemos — so adicionamos.

1

Hero – coluna no mobile, linha no desktop

/* hero.css – BASE MOBILE */
section.hero {
  flex-direction: column;   /* texto em cima, imagem embaixo */
  text-align: center;
  padding: 1.5rem 1.25rem;
  gap: 2rem;

  & h1 { font-size: var(--text-3xl); }  /* 48px */

  & .buttons {
    justify-content: center;
    flex-wrap: wrap;
  }

  & .image-wrapper .ellipse { width: 18rem; }
  & .image-wrapper .patins  { width: 22rem; }
}

/* hero.css – DESKTOP (min-width) */
@media (min-width: 1024px) {
  section.hero {
    flex-direction: row;      /* texto e imagem lado a lado */
    text-align: left;
    padding: 2.5rem 2rem;
    gap: 0;

    & h1 { font-size: var(--text-4xl); }  /* 80px */

    & .buttons {
      justify-content: flex-start;
      flex-wrap: nowrap;
    }

    & .image-wrapper .ellipse { width: 28rem; }
    & .image-wrapper .patins  { width: 36rem; }
  }
}

Animacoes

Todas as animacoes do projeto em um lugar so

@keyframes slideUp

Palavras rotativas no hero. Controlada por tempo.

animation: slideUp 5s 2s infinite ease;

@keyframes float

Patins subindo e descendo suavemente.

animation: float 3s ease-in-out infinite;

@keyframes spin

Estrelas girando. Uma no sentido reverso.

animation: spin 6s linear infinite;
animation-direction: reverse;

@keyframes rolling

Faixa de texto rolando infinitamente.

animation: rolling 20s linear infinite;

Checklist

Ordem para construir o projeto do zero

  1. Crie a estrutura de pastas com assets/, styles/ e index.html
  2. Escreva o global.css com reset, variaveis e body
  3. Monte o HTML completo de todas as secoes no index.html
  4. Estilize o header — Flexbox, imagens com hover e badge do carrinho
  5. Estilize a hero (mobile) — column, centralizado, sem alturas fixas
  6. Adicione os @keyframes — slideUp, float, spin
  7. Expanda a hero para desktop — row, imagem ao lado do texto
  8. Estilize o banner — rolling infinito e gradiente animado
  9. Estilize a gallery (mobile) — 1 coluna, sem animation-timeline
  10. Adicione o grid assimetrico no desktop com grid-template-areas
  11. Adicione animation-timeline: view() nas figuras
  12. Estilize o footer — column no mobile, row no desktop, underline animado
  13. Teste em 3 larguras: 375px, 768px e 1280px com DevTools

Use o DevTools do Chrome (F12 → icone de celular ou Ctrl+Shift+M) para simular diferentes tamanhos. Comece pelo menor (375px) e va aumentando. Se funcionar em 375px e 1280px, funciona em tudo.
