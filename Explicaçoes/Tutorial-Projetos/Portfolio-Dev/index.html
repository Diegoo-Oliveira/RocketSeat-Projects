Leitura do layout

Separe o portfolio por secoes antes de escrever CSS

O layout real tem um topo escuro com elementos de codigo nas laterais, foto circular, texto de boas-vindas, titulo "Desenvolvedora Fullstack", descricao curta, tags de tecnologia, seis projetos, tres servicos e quatro links de contato. Use o node `3:376` do Figma como ponto de partida para conferir hierarquia, espacamentos e ordem das secoes.

Cada bloco tem uma responsabilidade. Quando voce nomeia essas responsabilidades no HTML, o CSS fica menos confuso e mais facil de comparar com a versao do professor.

Estrutura

Comece com pastas pensadas para crescer

Para um portfolio pequeno, um unico `styles.css` funciona. Para estudar como profissional, vale separar base, utilitarios, componentes e secoes. Essa divisao deixa a comparacao com o professor muito mais objetiva. 

Projetos/PortfolioDev/
  index.html
  assets/
    icons/
    images/
  styles/
    global.css
    utility.css
    components.css
    sections.css
    index.css
Passo 1

Monte o HTML com secoes semanticas

Escreva primeiro a estrutura. Deixe as classes descreverem o papel de cada parte, nao apenas a aparencia. 

<body>
  <main>
    <section class="intro container">...</section>
    <section class="projects section">...</section>
    <section class="services section">...</section>
    <section class="contact section">...</section>
  </main>
</body>
Passo 2

Transforme o visual do Figma em tokens no `:root`

Cores, fonte, largura maxima e espacamentos devem nascer em `global.css`. Assim, se voce mudar uma cor depois, o portfolio inteiro acompanha a decisao. 

:root {
  --gray-100: #e2e4e9;
  --gray-200: #c0c4ce;
  --gray-300: #878ea1;
  --gray-400: #292c34;
  --gray-500: #16181d;
  --gray-600: #0d0e11;
  --red: #e3646e;
  --purple: #bb72e9;
  --blue: #3996db;
  --green: #82bc4f;
  --yellow: #eabd5f;
  --container: 1040px;
  --radius-card: 12px;
  --gap: 24px;
}
Passos 3 a 8

Construa de componentes para secoes

3

Crie utilitarios pequenos

`.container`, `.section`, `.section-header` e `.grid` evitam que cada bloco repita largura, margem e alinhamento. 

.container {
  width: min(var(--container), 100% - 48px);
  margin-inline: auto;
}

.section {
  padding-block: 72px;
}
4

Monte a intro como uma secao centralizada

A primeira dobra nao e um header comum. Ela funciona como uma apresentacao: foto, saudacao, titulo grande, paragrafo e badges. 

.intro {
  min-height: 750px;
  display: grid;
  place-items: center;
  text-align: center;
  background: url("../assets/images/Background_Intro.png") center / cover;
}
5

Padronize badges de tecnologia

Nao crie uma classe nova para cada tecnologia se a estrutura visual for a mesma. Use uma classe base e, se precisar, uma variacao de cor. 

.tech-tag {
  display: inline-flex;
  align-items: center;
  gap: 8px;
  padding: 8px 14px;
  border-radius: 999px;
  background: var(--surface);
}
6

Transforme os seis projetos em cards reutilizaveis

A secao "Meu trabalho" tem seis cards com a mesma estrutura. Uma classe unica deixa o HTML menor e a manutencao mais simples. 

.project-card {
  display: grid;
  gap: 20px;
  padding: 12px;
  border-radius: var(--radius-card);
  background: var(--surface);
}

.project-card img {
  width: 100%;
  aspect-ratio: 16 / 10;
  object-fit: cover;
  border-radius: 8px;
}
7

Use Grid em projetos e servicos

Projetos aparecem em duas linhas de tres cards. Servicos aparecem em uma linha de tres cards. Grid resolve os dois casos. 

.projects-grid,
.services-grid {
  display: grid;
  grid-template-columns: repeat(3, minmax(0, 1fr));
  gap: var(--gap);
}
8

Use Flexbox nos links de contato

Na area final, cada link tem icone, texto e seta. Flexbox alinha esses itens sem precisar criar uma grade maior. 

.contact-link {
  display: flex;
  align-items: center;
  justify-content: space-between;
  gap: 12px;
}
Responsivo

Quebre as grades sem perder a hierarquia

No mobile, o portfolio deve continuar parecendo intencional. Reduza colunas, mantenha espacamento consistente e garanta que cards e botoes tenham area de toque confortavel. 

@media (max-width: 900px) {
  .projects-grid,
  .services-grid {
    grid-template-columns: repeat(2, minmax(0, 1fr));
  }
}

@media (max-width: 620px) {
  .container {
    width: min(100% - 32px, var(--container));
  }

  .projects-grid,
  .services-grid {
    grid-template-columns: 1fr;
  }
}
Checklist final

Como comparar com a versao do professor

  1. As secoes principais aparecem na mesma ordem do layout?
  2. Os estilos repetidos viraram componentes reutilizaveis?
  3. As cores e espacamentos importantes estao centralizados em tokens?
  4. O CSS esta dividido por responsabilidade, e nao por improviso?
  5. O responsivo quebra as grades antes de o conteudo ficar apertado?
  6. O README explica objetivo, tecnologias e como visualizar o projeto?
