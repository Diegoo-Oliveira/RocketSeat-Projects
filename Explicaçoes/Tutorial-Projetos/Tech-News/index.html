Tutorial de projeto

Como recriar o Tech News usando Flexbox e CSS Grid

A ideia nao e copiar tudo de uma vez. Primeiro voce le o Figma como blocos, depois decide quais partes sao layout de pagina com Grid e quais partes sao alinhamento de componentes com Flexbox.

Leitura do Figma

Antes de escrever CSS, separe a tela em regioes

No projeto Tech News, o layout tem uma hierarquia bem clara: cabecalho, menu de categorias, area de destaques, mais lidas, coluna de inteligencia artificial e uma lateral com anuncio e links.

Quando voce reconhece essas regioes, fica mais facil escolher a ferramenta certa: Grid para dividir areas grandes e Flexbox para alinhar itens pequenos dentro dessas areas.

Regra pratica

Quando usar Grid e quando usar Flexbox?

Use CSS Grid

Quando voce precisa criar colunas e linhas ao mesmo tempo, ou posicionar regioes grandes da pagina.

  • area de destaque: noticia grande + grade 2x2
  • mais lidas: quatro cards lado a lado
  • parte final: conteudo principal + aside

Use Flexbox

Quando voce quer alinhar itens em uma direcao, normalmente linha ou coluna, dentro de um componente.

  • menu: icone + texto
  • titulo de secao: texto de um lado, link do outro
  • card horizontal: texto + imagem
Passo 1

Crie a estrutura HTML antes de pensar em detalhes visuais

Comece com nomes de classes que representem as partes do layout. Isso ajuda voce a enxergar a pagina como blocos, nao como um monte de tags soltas. 

<body>
  <header class="site-header">
    <nav class="primary-nav">...</nav>
    <nav class="category-nav">...</nav>
  </header>

  <main class="container">
    <section class="featured-grid">...</section>
    <section class="popular-grid">...</section>
    <section class="main-columns">...</section>
  </main>
</body>
Passo 2

Transforme medidas repetidas do Figma em variaveis CSS

O Figma mostra um fundo escuro, um container centralizado, espacamento de 16px entre cards e 32px nas laterais. Coloque isso no `:root`. 

:root {
  --bg-color: #0f172a;
  --text-primary: #f1f5f9;
  --text-secondary: #cbd5e1;
  --brand: #60a5fa;
  --brand-dark: #1d4ed8;
  --stroke: #1e293b;
  --container: 1216px;
  --gap: 16px;
}
Passos 3 a 8

Monte o layout de fora para dentro

3

Header principal: Flexbox

O topo tem tres grupos na mesma linha: Menu, logo e Buscar. Esse e um caso classico de Flexbox com `justify-content: space-between`. 

.primary-nav {
  height: 72px;
  display: flex;
  align-items: center;
  justify-content: space-between;
}
4

Menu de categorias: Flexbox

As categorias ficam em uma linha. Use `display: flex` e permita rolagem horizontal no mobile. 

.category-nav {
  display: flex;
  justify-content: space-between;
  gap: 24px;
  overflow-x: auto;
}
5

Area de destaques: Grid

Aqui voce tem duas colunas: uma noticia grande e uma coluna com quatro noticias menores. Grid deixa essa divisao direta. 

.featured-grid {
  display: grid;
  grid-template-columns: 1fr 592px;
  gap: 16px;
}

.featured-list {
  display: grid;
  grid-template-columns: repeat(2, 1fr);
  gap: 16px;
}
6

Card com imagem e texto por cima

Para criar o efeito do Figma, o card vira `position: relative`. A imagem ocupa tudo e o conteudo fica absoluto no rodape. 

.story-card {
  position: relative;
  overflow: hidden;
  border-radius: 4px;
}

.story-card img {
  width: 100%;
  height: 100%;
  object-fit: cover;
}

.story-content {
  position: absolute;
  left: 24px;
  right: 24px;
  bottom: 24px;
}
7

Mais lidas: Grid de quatro colunas

Como os cards tem o mesmo peso visual, use `repeat(4, 1fr)`. Depois, no responsivo, reduza para duas colunas e entao uma. 

.popular-grid {
  display: grid;
  grid-template-columns: repeat(4, 1fr);
  gap: 16px;
}
8

Conteudo + aside: Grid no pai, Flex nos filhos

A divisao entre coluna principal e lateral e Grid. Dentro de cada noticia horizontal, Flexbox resolve o alinhamento texto + imagem. 

.main-columns {
  display: grid;
  grid-template-columns: 696px 488px;
  gap: 32px;
}

.horizontal-card {
  display: flex;
  align-items: center;
  gap: 16px;
}
Responsivo

Quebre as colunas quando faltar espaco

O segredo e nao tentar manter o desktop espremido no celular. Quando a tela fica menor, as colunas viram uma coluna so. 

@media (max-width: 900px) {
  .featured-grid,
  .main-columns {
    grid-template-columns: 1fr;
  }

  .popular-grid {
    grid-template-columns: repeat(2, 1fr);
  }
}

@media (max-width: 600px) {
  .featured-list,
  .popular-grid {
    grid-template-columns: 1fr;
  }
}
Checklist final

Ordem sugerida para voce praticar

  1. Crie `index.html`, `styles.css` e uma pasta `assets`.
  2. Monte apenas o HTML, sem tentar deixar bonito ainda.
  3. Defina cores, fonte, container e espacamentos no `:root`.
  4. Use Flexbox no header e nos componentes pequenos.
  5. Use Grid nas regioes grandes da pagina.
  6. Adicione imagens e overlays dos cards.
  7. Por ultimo, escreva os media queries.
