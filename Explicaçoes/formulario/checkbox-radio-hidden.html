Checkbox, Radio e Hidden

Esses tres inputs resolvem escolhas comuns: marcar varias opcoes, escolher apenas uma opcao e enviar um valor que nao aparece na tela.

Quando usar

  • checkbox: varias escolhas podem ficar marcadas.
  • radio: apenas uma escolha por grupo.
  • hidden: envia um dado invisivel para o usuario.

HTML

<input type="checkbox" name="interesses" value="html" />

<input type="radio" name="turno" value="manha" />
<input type="radio" name="turno" value="noite" />

<input type="hidden" name="origem" value="guia-formulario" />

CSS

input[type="checkbox"],
input[type="radio"] {
  width: 18px;
  height: 18px;
  accent-color: #0f766e;
}

Radios que compartilham o mesmo name fazem parte do mesmo grupo de escolha unica.
