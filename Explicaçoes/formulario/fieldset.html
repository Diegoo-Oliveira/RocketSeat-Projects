Voltar para formularios Fieldset

Fieldset

fieldset agrupa campos relacionados. A tag legend funciona como titulo do grupo e ajuda o usuario a entender aquela parte do formulario.

Funcoes principais

  • Organiza formularios grandes em blocos menores.
  • Da contexto para radios, checkboxes e grupos de endereco.
  • disabled pode desativar todos os campos do grupo.

Exemplo visual

Endereco

HTML

<fieldset>
  <legend>Endereco</legend>

  <label for="rua">Rua</label>
  <input id="rua" name="rua" type="text" />

  <label for="cidade">Cidade</label>
  <input id="cidade" name="cidade" type="text" />
</fieldset>

CSS

fieldset {
  display: grid;
  gap: 12px;
  padding: 16px;
  border: 1px solid #cbd5e1;
  border-radius: 14px;
}

Use fieldset quando os campos fazem parte da mesma pergunta ou do mesmo bloco de informacao.
