HTML Forms

A tag form cria a area que junta campos, botoes e dados. Ela diz para onde os dados vao, qual metodo sera usado e quais campos pertencem ao mesmo envio.

Para que serve

  • action indica a URL que recebe os dados.
  • method define como os dados serao enviados.
  • name em cada campo vira o nome da informacao enviada.
  • submit dispara o envio do formulario.

Exemplo visual

HTML

<form action="/cadastro" method="post">
  <label for="nome">Nome</label>
  <input id="nome" name="nome" type="text" />

  <label for="email">Email</label>
  <input id="email" name="email" type="email" />

  <button type="submit">Enviar</button>
</form>

O HTML define a estrutura e o significado. O CSS cuida da aparencia, do espacamento e dos estados visuais.

CSS

form {
  display: grid;
  gap: 14px;
}

input,
button {
  min-height: 44px;
  border-radius: 10px;
}
