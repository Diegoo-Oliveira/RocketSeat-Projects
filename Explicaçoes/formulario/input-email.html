Input Email

input type="email" indica que o campo espera um endereco de email. O navegador valida o formato antes do envio.

Funcoes principais

  • Mostra teclado melhor em celulares.
  • Exige formato parecido com nome@dominio.com.
  • Combina bem com autocomplete="email".

Exemplo visual

Digite um email valido para continuar.

HTML

<label for="email">Email</label>
<input
  id="email"
  name="email"
  type="email"
  placeholder="voce@email.com"
  autocomplete="email"
  required
/>

CSS

input:focus {
  border-color: #0f766e;
  box-shadow: 0 0 0 4px rgba(15, 118, 110, 0.14);
}
