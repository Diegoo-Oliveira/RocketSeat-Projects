Input Number

input type="number" recebe numeros e pode limitar valor minimo, valor maximo e intervalo de aumento.

Funcoes principais

  • min define o menor valor aceito.
  • max define o maior valor aceito.
  • step define de quanto em quanto o valor sobe.
  • value define um valor inicial.

Exemplo visual

Escolha de 1 a 10 unidades.

HTML

<input
  id="quantidade"
  name="quantidade"
  type="number"
  min="1"
  max="10"
  step="1"
  value="2"
/>

CSS

input[type="number"] {
  width: 100%;
  min-height: 44px;
  padding: 10px 12px;
}
