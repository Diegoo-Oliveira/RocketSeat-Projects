Input Password

input type="password" oculta o texto digitado na tela. Ele e usado em login, cadastro e confirmacao de senha.

Funcoes principais

  • Esconde os caracteres visualmente.
  • minlength ajuda a exigir tamanho minimo.
  • autocomplete ajuda o navegador a preencher senhas.

Exemplo visual

Use pelo menos 8 caracteres.

HTML

<input
  id="senha"
  name="senha"
  type="password"
  minlength="8"
  autocomplete="current-password"
  required
/>

CSS

input[type="password"] {
  letter-spacing: 0;
  border: 1px solid #cbd5e1;
  border-radius: 10px;
}

O tipo password so esconde na tela. A seguranca real depende de envio seguro e armazenamento correto no servidor.
