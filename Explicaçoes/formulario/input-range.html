Input Range

input type="range" cria um controle deslizante. Ele e util quando a pessoa escolhe intensidade, volume, preco ou nota.

Funcoes principais

  • min define o comeco da faixa.
  • max define o fim da faixa.
  • step define os intervalos do controle.
  • value posiciona o marcador inicial.

Exemplo visual

0 10

HTML

<input
  id="satisfacao"
  name="satisfacao"
  type="range"
  min="0"
  max="10"
  step="1"
  value="7"
/>

CSS

input[type="range"] {
  width: 100%;
  accent-color: #0f766e;
}

Para mostrar o valor mudando em tempo real, normalmente voce usa JavaScript junto com output.
