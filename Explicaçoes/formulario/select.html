Voltar para formularios Select

Select

select cria uma lista de opcoes. Ele e bom quando a pessoa precisa escolher uma alternativa de um conjunto conhecido.

Funcoes principais

  • option representa cada escolha.
  • value e o dado enviado quando a opcao e escolhida.
  • selected define uma opcao inicial.
  • optgroup agrupa opcoes relacionadas.

Exemplo visual

HTML

<select id="trilha" name="trilha" required>
  <option value="">Selecione uma trilha</option>
  <optgroup label="Front-end">
    <option value="html-css">HTML e CSS</option>
    <option value="javascript">JavaScript</option>
  </optgroup>
</select>

CSS

select {
  width: 100%;
  min-height: 44px;
  padding: 10px 12px;
  border-radius: 10px;
}
