# Zingen - Landing Page 🎵

Uma landing page moderna, responsiva e elegante para a plataforma de karaokê **Zingen**. Este projeto faz parte dos desafios práticos de desenvolvimento web front-end da Rocketseat.

## 🚀 Sobre o Projeto

A **Zingen** é uma aplicação focada em tornar o ato de cantar acessível, divertido e simples para qualquer pessoa. Esta landing page foi projetada com foco em experiência do usuário (UX), trazendo um design dinâmico, moderno, com gradientes vibrantes e elementos visuais que representam a energia da música.

> "Quem canta seus males espanta. Cantar nunca foi tão fácil."

## 🛠️ Tecnologias Utilizadas

O projeto foi construído utilizando as melhores práticas de desenvolvimento front-end moderno:

*   **HTML5:** Estruturação semântica de toda a página.
*   **CSS3 (Vanilla):** Estilização customizada completa, incluindo:
    *   Flexbox e CSS Grid para layouts responsivos e alinhamentos complexos.
    *   Efeitos de iluminação de fundo (*backlight*) usando gradientes dinâmicos.
    *   Estilos globais estruturados e modulares (botões, seção hero, navegação).
*   **Google Fonts:** Utilização da fonte moderna *Inter*.
*   **Vectores SVG:** Ícones e ilustrações em alta resolução.

## 📁 Estrutura de Arquivos

```text
Zingen/
├── assets/          # Imagens, mockups e ícones do projeto
├── styles/          # Arquivos de estilização CSS
│   ├── fields/      # Estilos de componentes específicos (ex: botões)
│   ├── global.css   # Estilos globais e resets de CSS
│   ├── hero.css     # Estilos específicos da seção de destaque (Hero)
│   ├── index.css    # Ponto de entrada de estilos
│   └── nav.css      # Estilos da barra de navegação
├── index.html       # Estrutura principal da página
└── .gitignore       # Arquivos ignorados pelo Git
```

## 🎨 Design e Funcionalidades

*   **Navegação Fluida:** Header completo com logomarca, links rápidos e call-to-action (CTA) para download do aplicativo.
*   **Hero Section Impactante:** Título forte com animação e imagens ilustrativas que trazem o conceito do aplicativo de forma visualmente incrível.
*   **Micro-interações:** Botões estilizados com estados de hover e transições suaves que melhoram o feedback visual.
*   **Responsividade:** Projetado para se adaptar perfeitamente a diferentes tamanhos de tela.
