# RocketSeat Workspace

Workspace de estudos com paginas de explicacao, tutoriais guiados, projetos
feitos manualmente e projetos de referencia da Rocketseat.

Use este README como mapa geral para encontrar rapidamente cada site dentro da
pasta raiz.

## Entrada principal

- [Home do workspace](index.html) - pagina inicial com atalhos para todas as
  areas principais.

## Projetos manuais

Projetos que voce constroi na mao durante os estudos.

- [Travelgram](Projetos/Travelgram/index.html) - perfil de viagens com layout,
  assets, header, main, footer e estilos separados.
- [TechNews](Projetos/TechNews/index.html) - portal de noticias sobre tecnologia
  com destaque principal, secoes de noticias, aside e assets proprios.
- [Portifolio Dev](Projetos/PortifolioDev/index.html) - portfolio pessoal em
  desenvolvimento avancado, baseado no desafio Portfolio Dev da Rocketseat.

## Tutoriais de projetos

Guias para transformar um layout em projeto com uma estrutura mais profissional.

- [Central de tutoriais](Explicaçoes/Tutorial-Projetos/index.html) - hub dos
  tutoriais guiados por projeto.
- [Tutorial Tech News](Explicaçoes/Tutorial-Projetos/Tech-News/index.html) -
  roteiro para entender onde usar Grid, Flexbox e componentes no portal de
  noticias.
- [Tutorial Portfolio Dev](Explicaçoes/Tutorial-Projetos/Portfolio-Dev/index.html) -
  roteiro para montar o portfolio com intro, projetos, servicos, contato,
  tokens, utilitarios e componentes.
- [Guia SVG e cores](Explicaçoes/SVG-Cores/index.html) - estudo sobre `fill`,
  `stroke`, `currentColor` e hover de icones SVG.

- [Catalogo de explicacoes](Explicaçoes/index.html) - indice geral das paginas

  eixo cruzado, gap, alinhamentos e children.

  areas, grid automatico e alinhamentos.

- [CSS Profissional](Explicaçoes/CSS%20Profissional/index.html) - comparacao de

## Fluxo de estudo sugerido

1. Abra a [Home do workspace](index.html).
2. Estude o conceito em `Explicaçoes`.
3. Construa sua propria versao em `Projetos`.
4. Use um tutorial em `Explicaçoes/Tutorial-Projetos` para revisar a estrutura.
5. Compare com o codigo do professor em `RocketSeat-Projects`.
6. Refatore seu projeto aos poucos, mantendo cada etapa funcionando.

## Observacoes

- `Projetos` guarda suas implementacoes manuais.
- `RocketSeat-Projects` guarda referencias feitas pelo professor.
- `Explicaçoes/Tutorial-Projetos` guarda roteiros de construcao e comparacao.
- `PortifolioDev` esta escrito com "i" na pasta atual. Se for renomear para
