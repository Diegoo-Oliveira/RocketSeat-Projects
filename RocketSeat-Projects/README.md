# RocketSeat Projects

Pasta reservada para guardar projetos de referencia feitos pelo professor da
Rocketseat.

Use estes codigos como material de comparacao depois de terminar sua propria
versao dentro de `Projetos/`. A ideia nao e copiar primeiro, e sim comparar
estrutura, nomes de classes, organizacao dos arquivos CSS e padroes que podem
melhorar seus projetos manuais.

## Projetos disponiveis

- `portal-de-noticias-main/` - referencia da Rocketseat para o projeto Tech
  News.

## Como usar

1. Termine sua implementacao em `Projetos/`.
2. Abra a referencia correspondente nesta pasta.
3. Compare a estrutura HTML e a divisao dos arquivos CSS.
4. Anote o que ficou melhor no codigo da referencia.
5. Refatore sua versao aos poucos, mantendo a pagina funcionando.

## Links locais

- Guia visual desta pasta: `index.html`
- Sua versao do TechNews: `../Projetos/TechNews/index.html`
- Tutorial Tech News: `../Explicaçoes/Tutorial-Projetos/Tech-News/index.html`

## Observacao

Esta pasta nao substitui seus projetos manuais. Ela funciona como uma biblioteca
de comparacao para revisar escolhas de codigo depois da pratica.
